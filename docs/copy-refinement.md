# 观看界面与冗余文案清理

## 本轮范围与方案（2026-11-01）

用户要求删除大图悬停时的尺寸、左右切换和 Esc 提示，并检查其他页面的多余文案。场景是摄影观看与日常相簿、画册操作；让作品承担视觉主体，动作由清晰按钮表达。保持当前背景、字体、卡片、胶囊导航及照片构图，不重新设计外观。

清理照片区域原生 title、重复教学、装饰标语和无操作意义的标签。保留图标按钮动作名称、截断内容全名、键盘可访问描述、必要空态、错误、风险确认与版本/保存语义。键盘快捷键继续可用，关闭和返回行为不改。

## 实施

- 大图预览：删除照片舞台的尺寸/快捷键 title 和标题上重复相簿上下文 title；保留 aria 描述、左右切换、Esc、静止隐藏工具栏与窗口拖动。
- 图库：删除“展览/总览”文字按钮上重复的悬浮标题。
- 画册：阅读页去常驻快捷键、“适合窗口”和重复“画册阅读”标签，页码及翻页居中；编辑页正常状态不再显示点击教学，未保存提醒保留；删除两个与字段标签重复的 placeholder；简化书架与加入画册空态。
- 设置及应用外壳：删除装饰眉题、仅含品牌与标语的 about 区块、重复页面名与标语页脚。品牌定位本身不变。
- 欣赏播放器：配乐说明保留会话范围，去掉无关 AI 说明；预览/播放器/阅读图标提示简化为动作名称。

AI 发送和费用、Key 与模型限制、备份恢复、原图替换、未保存离开、废弃/删除与取舍范围等必要信息均保留。区域框选仅在操作模式内出现的说明保留。纸张文字、导出文档及数据不变。

## 验收依据

在独立深色验收图库使用真实摄影内容，检查照片上不再出现该原生 Help/title；实际切换、返回、工具栏隐藏仍正常；检查设置、书架、编辑与阅读的层级和翻页对齐。类型检查及 release 构建不能替代原生检查。桌面证据位于 `.build/verification/copy-refinement/`。
