# 产品约定

## 作品目录绑定

在设置的「作品目录」区绑定、重新定位或解除绑定。作品页在未绑定且没有相簿或待同步相簿时，提供通往设置的文字入口。一级子文件夹中的照片按文件夹加入作品相簿。确认同步后保存照片索引，原件留在来源目录。首次绑定、启动、运行中发现新增和目录重连共用「同步 / 忽略」确认。外部原件不可用时，相簿和画册仍可打开，在对应位置显示占位。详见[作品目录绑定](work-directory.md)。

## 统一照片来源（2026-11-04）

相簿导入、模特样片、策划场景参考和画册创建/编辑添加照片均提供本地照片及链接来源；原有业务选片同时保留图库来源。链接自动识别小红书或 Instagram 单篇图片帖子，先抓取并生成会话候选，默认不全选。用户选片并确认后才把选中候选写入正式图库；未选图片与取消会话清理，不因解析成功自动导入。相簿满额沿用原子取舍，先保留旧图，由用户明确决定是否废弃当前相簿关系；原件不删。

链接获取按已就绪张数显示进度，下一张照片的位置显示加载占位。每张候选准备好后按帖子顺序显示预览，整组就绪后可选片和确认。停止获取会清空本次预览，保留输入链接。

多选照片时，「全选」覆盖当前相簿、搜索结果或选片筛选范围的全部分页，并保留先前选中的照片。混合搜索页的预览按预览范围选择。达到选片上限的场景按当前列表顺序补足可选张数。「取消全选」清空本次选片。取舍里的「全部保留」和「全部不保留」作用于全部候选，仍需回顾和确认才保存。

新导入的本地照片只登记源文件路径、元数据和缩略图。此前入库的管理副本保留。文件缺失后仍可用缩略图浏览，查看原片时显示「找不到源文件」，照片 ID、标注和已有引用保留。源文件放回原路径后，重新打开即可读取。本地源文件需单独备份，从备份新建图库时本地引用仅恢复索引和缩略图。

策划上限计算原有选择和新增照片合计，保持每场景最多3张；已有参考ID与意图保留。画册新增照片进入当前编辑稿的章节/页面，不自动保存或覆盖既有未保存编辑。用户已明确确认导入图库后，再取消模特、策划或画册编辑只放弃业务文档引用，不删除已入库照片。来源保留可回看的帖子地址，平台会话与CDN访问签名不作为照片来源保存。

链接图片使用平台实际提供的静态版本，不承诺摄影上传原件或所有链接免登录成功；LIVE照片可取静态图片，视频帖子或混合视频、登录限制、验证码、列表不完整及下载失败明确报错。解析窗口不导入浏览器Cookie，不开放图库IPC。界面、实现与验收记录见[统一照片来源](photo-source-import.md)。

- UI 使用 Tailwind CSS 4 和 CSS 变量；动效使用 Motion，Radix 按需引入。

- 设计方案先于重要界面与交互实现，每轮同时交付设计质量与真实业务能力；范围和排期服从上述两条基调。不能以原型、静态页面或 mock 代替功能交付。
- 应用免费，计划开源；正式项目许可证与发布签名身份仍待确定。

## 已确认的产品范围

1. 摄影收藏：真实照片导入、分组、数量上限、标签、文字标注、来源记录和搜索；支持查看废弃照片。
2. 我的作品：组织自己拍摄的照片，按时间、地点或项目浏览；与收藏共同作为画册选片来源。
3. 文件管理：导入逐项报告成功或失败及原因，缺失文件可重新定位；重启后照片与元数据仍可用。
4. 画册：从收藏和作品中选片，编排顺序与章节。创建时按模板自动排版，之后可逐页编辑、保存、阅读和数字导出。
5. 应用内欣赏：从分组或画册播放照片，提供播放/暂停、前后切换、播放顺序与循环等策略，可选择本地音乐。
6. AI（暂不开放 UI）：暂时隐藏照片分析、设置接入及AI分析文字搜索，页面不加载AI配置或分析记录。组件、API、后端与单一模型接入能力保留，后续完善后再启用；图库、画册、欣赏和备份照常使用。
7. 数据备份与恢复：备份照片、图库关系、标注、画册和必要设置，支持增量恢复到当前图库；排除 API Key。
8. 人像模特：维护姓名／昵称、联系方式、城市、风格标签、备注、性别（男／女）、生日、身高和体重，以及有序样片与封面；档案属于当前本地图库。首页每行一位，左侧基础信息、右侧最多三张等高原比例样片；优先同构图方向，不足时竖左横右分组，包括空档案均保持固定行高，规则见[横向档案行](model-overview-rows.md)。点击进入只读详情查看已填资料和全部样片；详情与编辑均为紧凑资料卡置顶、样片在下方全宽展示，不显示“基本资料”“样片”分区标题；点击编辑后修改（见[资料置顶](model-profile-top.md)）；保存回到更新后的详情，新建取消回列表，已有档案取消或放弃修改回详情。编辑提供取消与保存，删除仅在列表删除图标及详情页头提供，进入统一确认后删除档案；编辑页不提供删除。浏览流程见[模特浏览与详情](model-browse-detail.md)。
9. 社交排版：从相簿选择照片后通过「模拟排版」进入，临时预览微信朋友圈多图动态、小红书图文笔记、Instagram 多图帖子。固定本地头像和昵称，按平台提供朋友圈文案、小红书标题／正文、Instagram 配文，三个平台平铺单行选择。排版不设独立顶部导航，不保存或提供草稿，退出直接结束；不包含导出或平台发布。

模特与社交排版的原始方案见 [模特与排版](models-social-plan.md)，临时预览最新约定以 [仅模拟预览](social-preview-only.md) 为准。模特性别以与风格标签一致的按钮直接单选，再点取消可恢复未填写；不要求手动输入。模特风格标签采用常用标签平铺点击多选，再点取消；选中不显示勾号；在标签末尾的管理图标打开弹窗，管理当前档案的全部可选标签，预设和自定义均可删除。可选目录与已选值分别随档案保存；明确清空目录后不自动恢复预设，未选的新标签也可保留，不使用下拉。规则与验证见[模特风格标签](model-style-tags.md)。模特样片引用图库稳定照片 ID，移除单张样片只调整当前档案的选片。删除整个档案时按图库的照片引用规则处理。模拟排版仅在内存中使用照片 ID，照片使用三列以上无文件名缩略图网格，直接拖动图片插入排序，右侧预览同步并按可用视区适配；支持键盘 Alt+左右逐张、上下按行调整。长文保留右侧局部滚动查看全文。平台切换保留完整选片及文案，小红书标题不串入其他平台。超过当前模拟数量时明确说明仅预览前 N 张，保留全部选片。平台显示裁切不修改原件；预览是布局模拟，不承诺与各版本客户端像素一致。

为拍摄搭配服装，模特资料卡在性别、生日下方并排提供身高（cm）与体重（kg），两项均可留空、填写小数或清空后保存。身高须大于 0 且不超过 300 cm，体重须为大于 0 的有限数值。详情只展示已填数值及单位；三围字段仍保留原值，不在界面显示。

模特编辑页的样片以照片呈现，单击可预览，右键或聚焦后按菜单键、Shift+F10 可查看或设置封面、调整顺序和移除样片。

数字导出本轮采用可独立打开的自包含 HTML，界面明确标注格式。原有约定没有 PDF 硬要求，本轮不以 HTML 冒称 PDF。云同步和系统屏保插件不属于本轮范围，欣赏是应用内功能。

## 全局搜索

顶栏放大镜与 `⌘K` / `Ctrl+K` 打开同一个搜索页。输入关键词后，同时展示当前图库中命中的照片、画册、模特和策划，按类型分组。每组提供预览、结果数量与进入完整结果的入口。照片覆盖收藏和作品，包含未归入相簿的照片。打开结果后可返回原关键词、类型及浏览位置。独立类别读取失败时显示重试，其他类别继续可用。创建画册的选片搜索和各模块内搜索仍按各自流程使用。

## 必须保留的规则

- 图库照片墙的临时选择只用于后续操作，不直接改变相簿关系、画册或原件；它与候选池的业务取舍独立。
- 废弃状态属于照片与分组的关系，只影响当前分组。
- 废弃照片仍可访问，默认不主动展示，不占该组有效名额。
- 废弃不得删除原文件、影响其他分组或改变已有画册。
- 满额时把新照片和原有照片一起取舍，确认前不提交变化。
- 取消新照片表示不加入；取消原有照片表示从当前分组废弃。
- 以上“取消照片”指在候选池中取消保留该照片；关闭或取消整个取舍对话框表示不提交任何业务变化。
- 恢复废弃照片、降低分组上限同样受容量约束；需要取舍时使用统一候选池，确认前不提交恢复、上限或成员状态变化。
- 候选池确认是一次原子业务提交，失败不得出现部分新增、部分废弃或上限提前变化。
- 已有画册以逐页编辑和保存为主。创建时选择的模板负责初次排版。已保存的画册内容可阅读、播放和导出。
- 书架只呈现摄影封面和书名，不显示照片数及版本数。封面由当前画册的页面、页内照片阅读顺序派生，取首个记录存在且原图和缩略图文件可用的照片；不新增封面编辑或持久化配置。文件不可用时跳过，全部不可用保留素色标题封面；实际图片解码失败须明确反馈。书架封面预览满铺正方形区域，以原比例居中裁切（`cover`），仅此入口允许裁切；不延展、不扩景，不改变照片原件、画册编辑器内页或导出。删除下方色带，真实原书名以本地双语展示字体直接叠图，局部图像分析和已有人工区域用于位置及字色选择；不新增AI请求、封面配置或持久化。极端长名明确省略并保留完整可访问名称；加载和分析失败不隐藏原名。见[艺术字摄影封面](book-cover-editorial.md)。
- 照片详情不再提供区域标注。已有区域标注保留在图库及备份中，编辑照片详情不改写这些记录。
- 文件缺失、导入失败、导出失败、恢复失败及 AI 请求失败应明确报告，不能静默伪装成功。
- 应用只打开一个本地图库。导出 ZIP 时可选择「仅图库资料」或「包含全部原片」。前者保存图库数据和缩略图，后者还保存图库中每张照片的原件，包括引用的本地文件和作品目录文件。完整备份遇到无法读取的原片时报告失败。
- 恢复补入当前图库缺少的记录，已有记录按 ID 保留。完整备份中新补入的照片使用 ZIP 内的原片作为图库副本，保留照片 ID。仅图库资料的备份中新补入的作品目录须重新定位，其他缺少原片的照片可单独重新定位。受相簿容量、已隐藏照片或已确认同步任务影响的冲突内容按结果提示处理。恢复失败保留现有图库内容。Key 不进入备份、普通业务导出或日志。

## 视觉方向

视觉方向与 UI 开发、验收依据统一见 [设计规范](design.md)。该规范取代此前“中性浅色工作区、黑白灰控件”的样式方向；历史截图和验收结论不代表已达到新规范。以照片和画册为中心，工具按场景出现，不强制使用永久侧边栏。支持窗口缩放、键盘操作及系统减少动态效果偏好。

相簿与画册卡片单击打开内容，右键管理；卡片获得焦点后可用 Shift+F10 或菜单键打开同一菜单。相簿信息及删除、画册重命名及删除通过该菜单访问，卡片不常驻管理按钮，新建入口保留。右键不打开内容，不改变照片选择；删除须确认。收藏和作品首页只陈列真实相簿，不展示“未归入相簿”或无相簿归属的照片；没有相簿时显示新建相簿空态。照片可独立于相簿存在。删除相簿、画册、模特档案或策划时，只检查此次删除涉及的照片。照片失去最后一个引用后退出全局搜索和图库选片。只要其他相簿、画册的当前内容、模特样片、策划参考或已保存的排版草稿仍在引用，照片就继续可用。原文件、图库副本及备份数据保留。规则与验收见[卡片管理](card-management.md)。

收藏和作品的相簿首页保留独立排序图标，图标随当前依据和方向变化。相簿详情通过三点菜单中的「照片排序」选择，五个选项直接平铺，当前选项带勾号。相簿按创建时间或相簿名双向排序，默认旧相簿在前。照片按拍摄时间或原始文件名双向排序，缺少有效拍摄时间时使用导入时间。名称中的数字按数值比较，例如 DSC_2 排在 DSC_10 前。相簿内照片默认按拍摄时间从新到旧连续展示，也可选择加入顺序。时间排序不设年月分隔。作品的地点和项目分组由用户单独选择，组内跟随时间方向，组间按每组最新照片的时间比较。按文件名排序时平铺，切回时间时恢复之前选定的分组。照片墙、单张、大图切换和相簿欣赏共用浏览顺序。相簿列表和相簿内照片各记住一项排序偏好。作品与收藏共用列表偏好，所有相簿共用照片偏好。两项选择在本机应用重启后继续生效。

相簿封面采用一致的陈列比例与标题/数量层级，照片墙仍完整呈现原作品。照片墙默认处于浏览模式，悬停不显示选择框或照片三点入口；普通单击打开已有大图预览，不改变选择；照片详情仍从右键菜单访问。大图预览为查看界面，承担观看、缩放拖动、左右切换和返回，不显示选择框、已选计数或通过空格改变照片墙选择。返回按钮保留左上位置，右上信息图标与其共用窗口控制所在高度的顶部单行，并为系统控制保留安全槽。默认不显示照片名称；点击信息图标按需展开深色小浮层，展示当前可见照片的信息。左右切换及页码位于图片下方独立的底部工具行，不覆盖照片；照片在扣除顶栏与底部工具行的舞台内按原比例适应窗口。返回按钮默认无底色、边框及阴影，保留轻量悬停、按下与键盘焦点反馈。静止约2秒后隐藏自定义顶部及底部工具，移动指针或键盘操作唤醒；工具栏悬停、键盘焦点及信息展开期间保持可操作，隐藏时保留顶部及底部工具行占位，前后照片位置和尺寸稳定。信息可再次点击图标、点击外部或按Escape关闭，切图时关闭；信息展开时第一次Escape仅关闭信息并返回触发按钮，后续Escape退出大图。照片操作通过桌面右键菜单及键盘菜单入口访问。右键选择第一张照片后进入选择模式，其他照片显示选择反馈并可单击增减选择；清空最后一张、取消选择、Escape 或切换相簿后恢复浏览模式，单击恢复打开大图预览。批量操作栏保留更多入口；对已选照片操作时批量范围明确，对未选照片操作时只针对该照片，不借用其他已选项。布局与简短命名承担说明，避免重复教学、文件信息和悬浮工具覆盖作品；必要空态、错误、风险确认及可访问名称保留。

大图信息浮层与照片右键菜单中的「详情」展示同一套照片信息。顶部优先显示焦距、光圈、快门与 ISO，随后按时间与地点、相机与镜头、文件分组。文件区显示名称、原文件名（与名称相同则省略）、像素尺寸、格式、大小和已有来源。实际焦距优先，35 mm 等效值单独标识。有记录时可展开查看曝光补偿、曝光模式、测光、白平衡和闪光灯。缺失项省略。时间和地点沿用图库记录及人工编辑结果。打开浮层或详情时按需只读当前照片的原件，新旧照片均适用，无需迁移。读取完成前保留已有信息；原件读取失败时保留已有信息并提示，EXIF 损坏时仍显示可读取的文件信息。浮层沿用单层中性深色材质；详情在照片下方展示信息，右侧保留文字标注和资料编辑。两处都以参数层级、对齐和留白分组。

收藏和作品的相簿详情在三点菜单左侧直接提供「展览」「总览」「单张」三个图标。单张模式在相簿内按原比例显示完整照片，底部按当前相簿顺序排列缩略图。点击缩略图或按左右方向键切换，首尾停止；当前照片的标记与批量选择分开。照片操作仍可通过右键菜单访问。搜索保留原有两种照片墙视图。

大图切换提前准备当前目标与相邻原图，等待时保留已显示照片，实际展示节点可显示后再交接；标题和页码与可见照片一致，快速切换以最后请求为准。正常切换不闪出加载文案，持续等待与失败保留必要反馈。过渡采用短促淡出与轻微方向位移，减少动态效果时直接交接；照片保持完整比例，不依赖动画完成决定可见性或退出。实施与验收见[大图切换](photo-review-transition.md)及[顶部单行工具栏](photo-review-titlebar.md)。

大图查看支持围绕指针滚轮缩放（适合窗口的1–8倍）、放大后左键拖动、双击照片在2倍与适合窗口之间切换。只作用于照片实际像素区域，边缘留白及顶部窗口手势独立；边界按实际图片尺寸约束，新显示照片或原图地址变化恢复适合窗口，同照片缩略图升级原图保留视角。滚轮合并连续输入并短促平滑收敛，首输入立即反馈、反向立即改向；拖动直接响应，双击用短促柔和过渡，动画中可反向双击或用滚轮、拖动从当前画面接管；减少动态效果时立即完成。不更改原文件或保存裁切。实施与验收见[大图缩放与拖动](photo-review-zoom.md)。

实施阶段与可验证验收场景见 [implementation-plan.md](implementation-plan.md)。清单完成状态必须依据实际代码和验证证据更新。


## 相簿封面

在收藏或作品相簿内右击一张有效照片，选择「设为封面…」。弹窗按首页卡片的 3:2 比例预览，可拖动或用方向键调整构图，也可缩放；点击「保存封面」更新当前相簿，取消保留上次封面。即使已选多张，取景也只针对右击的那张照片。再次为同一张照片取景时，沿用已保存的构图。

取景弹窗读取当前照片的原件。保存后在后台按选定构图生成高清封面。首页靠近可见区域的卡片优先呈现已有缩略图，高清封面可用后以相同构图替换。旧封面和默认封面随浏览按需生成。原件暂时不可用时，已生成的封面或已有的可用缩略图仍可展示。

取景只用于相簿首页卡片。没有自定义封面，或封面照片在此相簿中已废弃时，卡片沿用首张有效照片；恢复封面照片后，可再次显示已保存的构图。照片墙、原件和其他相簿不受影响。

## 相簿隔空投送

在 macOS 的收藏或作品相簿中，选片后通过批量栏「更多」或右击选中照片，使用「隔空投送」。右击未选中的照片只投送该照片。右击相簿卡片或打开相簿详情的「更多」可「隔空投送整本」，包含相簿内全部未废弃的照片。空相簿禁用此项。

macOS 系统窗口负责设备选择和传送。照片使用原始文件字节与文件名，同名时为副本加编号。任何所需原件无法读取时，提示对应文件并停止准备整批。取消后保留选片及相簿状态。

## 相簿拼图

在相簿中选择至少两张照片，经批量操作栏或右键「拼图」进入独立工作台，不增加顶部导航。选片仅来自同图库；工作台提供大预览、右侧布局工具与底部选片条。自适应与长图完整呈现原构图；网格可按照片独立等比裁切、拖动和缩放，支持恢复完整显示，均不改源文件。画布拖动交换与底部拖动插入分工明确，底条提供交换及 Alt+方向键替代，裁切状态用方向键调整位置。布局、选片、排序、裁切与背景均可撤销/重做。

拼图导出为无损 PNG。默认输出尺寸保留每张来源的有效像素密度：完整显示按全部原图计算，裁切按缩放后的实际取景区域计算；小尺寸来源不得拖低其他照片的清晰度，必要的等比放大不代表新增细节。预览参考尺寸不限制成片像素。导出时可编辑文件名、查看实际像素，或锁比例显式调整长边；降低时显示「已降低分辨率」并提供恢复原图尺寸入口。单边最多32768px，总像素最多1.6亿，最多100张；默认结果超限时仍可打开导出对话框，明确要求调整布局、选片或主动修改输出尺寸，绝不自动降低清晰度。不能表达为有效像素矩形的组合明确报错，不重叠或静默裁切。

每次导出通过系统窗口选择具体目录，再从原件合成 PNG。目录中已有同名文件时自动添加编号。取消选择目录或导出失败时保留拼图与导出设置。返回或导航有未导出保护，选择目录和导出期间阻止导航和窗口关闭。成功后回到原相簿，保持滚动位置与选择，浮动提示显示实际文件名。导出仅创建本地文件，图库和相簿关系不变。[早期相簿拼图方案](collage-plan.md)保留原流程的历史记录。

## 拍摄策划

「策划」为独立顶部工作区，属于当前本地图库。内容由简短拍摄概览、整体视觉、拍摄场景、执行准备组成。概览交代主题、方向、时间地点、出镜团队和成片用途。内部Part对应界面的场景，每个场景为独立卡片：单层中性深色浅底、可见细边界和克制圆角，紧凑标题与要点；卡内以“参考图”“拍摄参数”“镜头清单”三个短标题明确分区，上区图与参数并排、下区全宽文字清单。光影、镜头焦段、场地、造型、情绪及时间直接可见；阅读与编辑均不设展开收起。图片保持完整构图，参数统一单列标签和值，不随参考图数量分散为多列。镜头条目纵向组织，避免多层章节与零散表单。

策划首页每份策划独占一行，左侧显示标题、执行日期、已填写的拍摄时间和地点、最多两行摘要及数量，右侧按场景和参考的保存顺序展示最多两张不同照片的缩略图。拍摄时间与执行日期文字完全相同时，首页只显示一次。首页按执行日期从晚到早排序，同日按最近更新排序；旧策划未设执行日期时排在末尾。缩略图保留完整构图，跳过缺失或无法读取的照片，无可用图时省略预览区域。点击整行或通过键盘激活可打开策划。

全案概览通过日期选择器填写必选的「执行日期」，只记录日历日期，供首页浏览、排序和搜索。旧策划仍可读取，未设日期时在首页和概览注明，再次保存前须补选；不从拍摄时间文本或创建时间推算。

全案概览保留“拍摄时间”自由文本，交代整组时间范围或整体安排；各场景复用独立`timeWindow`为“拍摄时段”，在各场景标题旁展示并在同处编辑，作为场景一级阅读信息；长标题或时段空间不足时完整换行，拍摄参数区不重复显示。长图同步标题旁时段布局。支持自由填写时间范围及简短时段说明，页面阅读、编辑、搜索与长图一致；空项阅读省略，不根据全案时间推导各场景时段或自动计算光线。

整份策划的妆造、道具、器材为全案固定准备，在整体视觉之后、首场景之前以“整组准备”统一列出，支持阅读、编辑、搜索、保存、备份和PNG；空内容阅读时不占区域。旧全案缺字段时补空，不猜测拆分旧场景造型。已有场景造型与道具文字原位保留、可读可改，新场景不重复提供空造型字段。

场景可选1–3张参考并逐图填写参考意图；0张允许保存未完成草稿。新保存最多3张，错误指出具体场景。历史超过3张时完整读取、恢复、显示和导出，编辑提示整理，不截断或静默丢图。策划详情仅在场景参考区展示和编辑图片；全案和镜头级旧图片在首页、详情及长图中不再展示，也不提供这些层级的选图入口。旧引用及意图仍保存在文档与备份，不自动搬迁或删除；非空旧意图作为对应整体视觉或镜头拍法中的纯文字参考要点保留。

每个场景通过有序结构化镜头条目组织拍摄内容，不再提供自由文本“补充／补拍清单”的填写入口、阅读显示、搜索命中或PNG导出。旧`part.shotList`原文仍随保存、复制和备份保留，不迁移、猜测拆分或清除；没有结构化镜头时显示“暂无镜头”。镜头按逐条纵向组织：名称与优先级同排，关键拍法作为主正文紧随，镜头内容收拢到固定阅读宽度；构图/姿态/光线/情绪在下方统一单列标签和值，参考要点使用同一标签起点并降低视觉重量；阅读仅显示已填内容，编辑保留全部结构化字段。场景共同参数与镜头独立拍法分别保留，不按语义猜测合并或删除内容。旧参考要点置于对应镜头末尾，以文字显示，不插入图片。参考和镜头均保留独立稳定ID，同图跨位置说明独立。

场景、镜头、参考可排序及移除，删除含内容的场景或镜头须确认。移除单张参考图只调整当前策划内容。删除整份策划时按图库的照片引用规则处理。每份策划最多20场景、100结构化镜头、120参考条目。旧数据全部保留：旧v1的造型/光线/镜头清单进入「原拍摄安排」对应字段；已存在v2缺镜头清单或焦段字段时补空，不根据既有拍摄要点猜测或改写内容；旧有图片顺序、策划ID及时间保持。

阅读与编辑分开；保存失败保留输入，内部返回、导航与原生关闭保持未保存保护，保存或导出期间阻止离开和重复操作。

长图为独立1080像素宽PNG，采用连续中性白色纸面与章节排版：全案概览、只出现一次的整组准备、逐场景章节、执行准备。取消长图灰底沟槽、卡片圆角与描边，统一单层页边距；场景以浅细线、编号、标题及相邻时段建立边界，章节间距大于内部间距，应用内的场景卡片保持。妆造、道具、器材在首场景前按单列标签和值统一列出；每个场景按标题要点、参考图、拍摄参数、纯文字镜头清单组织，三区标题清楚，镜头文字及非空旧参考意图完整导出，图像仅来自场景引用。长图参考图最多两列；三张时第三张保持半列宽续行，历史超限图片完整续排，保持原比例和列内图文关系。正文40px、图注及标签36px，以手机缩放阅读为依据；缺图或解码失败明确拒绝，不静默漏项。单边最多32768像素、总像素最多4000万、文件最多64MiB，超限明确要求调整，不截断或降采样。每次导出通过系统窗口选择具体目录，确认后才渲染 PNG。目录中已有同名文件时自动添加编号，成功提示显示实际文件名。取消选择目录时停留在当前策划，文件和相簿关系保持原样。导出供手机查看，不包含自动同步、现场打卡或移动端服务。
