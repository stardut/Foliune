# 模特资料置顶与全宽样片（2026-11-03）

用户要求详情与编辑页先显示／编辑基础信息，再在下方展示样片。本轮只改变两页的布局和阅读／键盘顺序，首页及存储不变。

详情在原页头下先呈现已填资料，基本字段横向分列，风格及备注按内容换行；下方全宽展示全部有序样片。空字段继续隐藏，空资料不占无意义整区。编辑表单置顶，姓名、联系、城市和性别、生日按合适列数组合，风格、备注保持完整可编辑；缩短普通备注输入的初始高度，避免把旧侧栏纵向拉长至整屏。导入及选片操作归下方样片区。宽窄窗均保持真实DOM中资料在前、样片在后。

沿用中性深色、现有控件和间距，以紧凑资料区和完整宽度的照片建立层级，不增加面板、分割线或说明文案。保持全部样片原序／完整构图、大图查看、保存与未保存保护、标签管理及旧字段透传。

验收检查详情／编辑结构顺序，表单与样片按钮语义、原有字段校验及标签回归；原生独立图库真实照片在宽窄窗核对顶部资料、样片起点和末尾、大图返回、编辑放弃；保存后详情通过组件回归核对，长内容保持可滚动访问。类型、构建和独立审查分别记录，不以构建代替原生设计验收。

## 2026-11-03 顶部资料紧凑化方案

用户要求减少顶部留白，让首屏多展示样片。本轮仅收紧详情与编辑页的局部页头、标题、字段及分节间距；详情风格与备注在空间足够时并排，编辑保留清楚的字段分组并减少中窄窗冗余换行。保持字号、焦点、合理点击范围、完整内容和照片尺寸，不改变首页及业务。沿用现有中性深色、连续背景及克制控件，以密度和对齐提升照片占比。验收在同一独立release、同样摄影样本和宽窄窗进行前后对照，检查样片起点、内容与操作可达、字段和照片无裁切；类型、定向回归、构建及独立审查分别记录。

紧凑轮仅改`ModelDetail.tsx`与`models.css`：详情上下分组10px、字段标签和值4px，风格与备注auto-fit并排；页头下距16px、资料至样片20px、基本资料标题24px。编辑主次字段间距12px、标题下8px、列间16px、标签与控件4px，局部输入内距6px／10px但保持36px最小高，备注最小56px；移除1100px下额外整行，800px／600px继续分组／单列。样片高度、字号、焦点、标签点击尺寸、数据及首页不变。

现有12项模特检查、标签脚本、类型及前端构建通过；标准与独立macOS release均成功，仍仅既有导入／chunk提示。Avenil管理独立release，实际退出旧进程后加载新包；同一林间档案4张真实摄影，宽1320×880对照样片起点详情约476→349px、编辑约469→409px（截图目测近似值），照片尺寸不变。窄949×621检查18标签、备注及短字段完整，End可达全部照片与编号，返回正常；Tab可进入姓名输入，焦点沿边清楚。旧窄图921宽，不作严格同尺寸量化。数据前后5档案／13引用只读比较完全相同。

## 2026-11-03 资料卡片与删除入口方案

用户要求移除“基本资料”“样片”可见标题、进一步减少留白，同时明确基础资料放入一张卡片；编辑提供取消且不显示删除，删除应在列表与详情可用。本轮采用单个紧凑中性暗面资料卡，以既有细边与约16px内距承托资料；保留表单和分区的无障碍名称，移除可见标题及纯标题占位。样片区直接呈现照片，编辑仅保留必要选片／导入工具。取消复用未保存保护；删除在列表的轻量更多／右键菜单及详情页头进入统一确认，删除只移除档案关联，不改照片原件。验证可见标题、空态和卡片边界、取消／未保存保护、两入口确认及取消、宽窄照片构图与操作可达，独立审查与原生实测分别记录。

列表删除入口在本轮原生验收后收敛为直接删除图标（悬停或键盘焦点可见），与详情图标均直达统一确认，不新增原生菜单路径。此前方案中的右键／更多仅记录过程，最终以直接图标为准。

实现移除两页可见分节标题和样片计数，保留资料／样片aria名称，编辑字段fieldset也保留名称；资料卡使用soft/line/radius-control、14px纵／16px横内距，不加阴影。编辑删除入口和内部删除状态/API/Modal移出，显式取消与返回统一走leave。Workspace统一确认负责取消、错误、重复请求及忙态；列表使用article与两个同级button，边缘留白仍可点击进入，删除按钮不会重复触发打开；行高144px及照片算法／完整构图不变。最终use-context-menu逐字恢复本轮前基线，未增加菜单scope。
