# 单一 AI 接入

## 本轮方案

用户在设置配置一个模型，照片详情直接使用已保存的接入。以一份紧凑表单替换三家重复表单：提供方、模型、API Key、图像输入开关与保存／移除。沿用中性深色连续背景、现有输入框和按钮，无新增卡片底板或动画；保存为主操作，移除低调呈现。表单宽窗首行并列提供方与模型，Key独占下一行，窄窗保持可读和键盘顺序。

本次无历史数据，不实现旧配置迁移或兼容路径。SQLite以`ai_connection`单行约束唯一有效接入，IPC返回`connection | null`。保存替换唯一接入，不删除其他提供方的系统凭据。移除按钮仅在选中当前已保存提供方时显示，明确删除当前接入和对应系统Key。调用仍携带已显示的提供方，后端核对它与当前接入一致，拒绝过期或非当前提供方调用。

Key不回传、不入SQLite或日志。切换提供方立即清空输入的Key，只有当前已保存提供方允许留空保留；切换到其他提供方要求重新输入Key，避免串用或不透明启用旧凭据。保存／移除期间统一阻止重读、切库和工作区离开。无接入、纯文本模型及读取失败分别明确显示。

## 待验收

- 宽窗与窄窗：一个表单，层级与现有设置一致，控件可读、可达。
- 原生键盘：Tab顺序、提供方选择、图像输入切换、Enter保存；焦点克制清楚。
- 切换提供方清空Key；失败保留有效编辑，成功清空敏感输入；重读恢复保存值。
- 保存／移除期间切库、重读、导航禁用；加载失败不把旧数据当新数据。
- 照片分析无提供方选择器；无接入、纯文本、缺Key和读取失败均不能发送。
- Rust内存库：唯一约束、替换、移除、过期提供方拒绝、Key不入库与错误回滚。测试使用内存凭据替身，不访问系统Key。
- 不以构建和单元测试替代原生界面设计验收；真实AI、Windows与正式分发另行记录。

## 开发验证（2026-11-05）

通过 Avenil `Foliune 悬浮导航构建验证` 完成 TypeScript 检查与前端生产构建；构建保留既有的动态／静态 import 和大 chunk 提示。`Foliune 单模型Rust检查` 执行 `cargo test --locked ai`，18项通过，其中5项为单一接入内存库／凭据替身测试、2项为既有AI请求与响应测试。`Foliune 单模型表单检查` 的3项真实React组件测试通过：跨提供方清空Key与必填策略、保存期间禁用及失败保留输入、仅当前提供方显示移除，避免操作对象混淆。测试不访问系统凭据或真实图库。

开发检查确认后端不存在旧配置迁移及自动选择路径，SQLite单行约束有效，无配置及非当前提供方调用明确失败。实现文件均未超过500行。界面沿用现有控件、背景与间距体系，以一份表单和唯一保存操作减少竞争视觉重心；“高级”与“设计感和质感”的最终判断仍需独立原生界面验收。原生宽窄窗、系统凭据实际保存／移除、真实API、Windows及分发不以这些开发检查计为通过。

## 独立验收（2026-11-05）

独立审查未发现阻断缺陷，复核了单行约束、无隐式默认接入、提供方与Key隔离、设置操作互斥及失败状态；独立执行表单组件测试3项通过。最终移除入口仅在选择已保存提供方时出现。

macOS debug 原生实例为 `Foliune AI Review.app`，标识 `app.foliune.ai-review`，Avenil服务为 `Foliune 单模型验收`。通过专用配置构建，使用既有照片来源验收图库的独立副本（20张照片），没有修改用户图库或保存系统Key。宽窗截图2640×1760像素，窄窗1842×1242像素（约921×621逻辑尺寸）。证据在 `.build/verification/ai-single-connection/`，包括 `before.png`、`after-wide.png`、`after-narrow.png`。

- 宽窄窗均只显示一份表单；沿用连续中性深色与既有控件，提供方、模型、Key及保存层级清楚，窄窗滚动后底部操作完整可达。
- 原生提供方下拉以键盘选到DeepSeek，模型更新为对应起点；空Key提交被原生必填校验阻止并定位Key字段，未写入凭据。
- 将模型改为 `deepseek-chat`，图像输入取消勾选且禁用；Tab从模型移到Key，焦点沿输入框边界可辨。
- 在真实摄影相簿打开照片详情，原生可访问树确认AI区只有“接入设置”及“请先在接入设置中保存一个模型。”，没有提供方选择器。照片详情截图采集时工具报 `noWindowsAvailable`，此项保留操作观察而无截图证据。

本轮已测表单的布局、层级与现有设计语言一致，缩减重复结构，未新增材质或动画。成功保存／移除、失败保留编辑及Key清空的行为通过组件和内存凭据测试验证；系统Key实际保存／移除、已配置状态原生操作、真实AI请求、切库动态操作、不同壁纸、减少动态效果、Windows及正式分发未验证，不计为设计或功能全量通过。
