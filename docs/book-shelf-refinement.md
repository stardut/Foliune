# 摄影书架精修

日期：2026-11-04。范围仅为画册书架及其封面摘要；不改画册纸张、编辑器、导出和照片原件。

## 场景与设计

用户浏览已有摄影画册，通过照片和书名识别内容，再单击进入。采用已确认的「摄影图封面＋薄书脊」：在现有中性深色连续外壳上，以暖白中性纸张承载完整照片，上方照片为主体，下方留出独立书名排版区，系统无衬线、中等字重。封面不再放品牌与照片数，封面外仅显示「照片数 · 版本数」。

单本宽约 240px，窄窗收至 220px，少量画册不撑满整行。装订只用左侧薄暗部和右侧约 2px 纸边表达，去掉厚重黄绿渐变、层叠书块与重投影。悬停上移 2px、轻微加深柔影；键盘保留清晰焦点；系统减少动态效果时取消位移动画。书架样式全部限定于书架选择器，不影响独立画册纸张。

2026-11-04 追加精修：按用户反馈扩大封面照片、减少纸面留白，封面内边距收至上/右 12px、下 14px、左 16px，照片与标题间距收至 12px，书名区最小高度收至 36px，多行仍自然增高且最多显示三行。左上、左下圆角改为 6px，薄书脊暗部同步圆角；右角继续 3px。书宽、3:4 外比例、完整构图及封面派生规则保持，原生观感需以本次新截图复验，上一轮通过仅对应精修前界面。

## 封面数据与状态

`BookSummary.coverPhotoId` 是派生摘要，不新增数据库字段或封面编辑。以当前版本 `pages` 的数组顺序，再按各页 `items` 顺序查找首个有效照片，与阅读器的实际阅读顺序一致。现有编辑器 `organize` 会同步页面和章节选片顺序，Rust 也校验两者一致；仍直接使用页面顺序作为封面依据。

此处「有效」指照片记录存在，且管理原图和缩略图路径均指向文件，与已有图库快照和 `PhotoImage` 的可用性规则一致。不为书架解码整库图片；文件存在不能保证解码成功，实际读取失败由复用的 `PhotoImage` 明确显示错误，不在错误发生后悄悄换封面。缺失候选可按顺序跳过；全部不可用时保留素色标题封面，并简短显示「封面照片不可用」。

书架列表单次读取每本的当前版本及版本数，不再逐书读取全部历史详情。前端复用已有图库快照按 ID 取照片，不增加逐书详情请求。保存、切换当前版本或返回书架时，现有刷新链路带回新的封面 ID。相簿废弃不影响封面引用。

## 交互与验收

保留单击打开、右键重命名/删除、菜单键和 Shift+F10。图片错误不阻止打开画册；封面内部不嵌套修复按钮，修复仍走已有图库/编辑器入口。加载、列表空态及列表读取错误沿用现有反馈。

功能检查包括：当前版本封面、手动换序、历史切换、首张缺失与全部缺失、跨图库选片和相簿废弃不影响书架，类型检查、前端构建及画册定点 Rust 测试。设计需由独立验收者在真实原生应用用横竖、方图及混合内容检查宽窄窗口、少量/多本、长标题、加载/错误、悬停与减少动态效果；本方案和构建通过不表示视觉验收通过。
