# 统一照片来源与确认导入

## 本轮目标与交互

2026-11-04 用户授权相簿、模特、策划、画册同时支持本地照片、小红书和 Instagram 链接。链接抓取结果必须先供用户选片，最终确认前不进入正式图库。

照片来源对话框复用当前中性深色 Modal、分段控件、图库选片网格与焦点规则；照片采用 contain 完整构图，选择显示顺序，不在照片上堆叠文件信息。提供「图库 / 本地 / 链接」来源，原相簿导入只显示本地和链接，保留已有图库选片场景。链接用一处输入自动识别平台，不另建抓取工作区。状态为等待输入、解析、准备候选、选片、提交、完成或明确失败；加载可取消，取消直接卸载，无退出动画残留。默认不全选链接图片，选中后才允许确认。

## 提交边界

- 本地和链接图片只进入当前会话候选暂存。解析与预览期间正式 photos、originals、相簿及业务引用不变。
- 用户确认时只提交选中候选；未选与取消的候选清理。相簿继续受容量约束，满额进入既有原子取舍，不偷偷废弃旧图。
- 模特、策划、画册在图片确认入库后更新编辑中的照片引用。随后取消业务编辑只放弃文档引用，不删除已经显式确认导入的图库图片。
- 策划每场景最多3张，限制作用于原有已选与本次新增的合计，由用户选，不截断帖子图片。画册创建和编辑添加照片都覆盖，保留章节和顺序。
- 当前图库在请求开始时绑定；取消、关闭、导航、切库或失败不能让过期请求写入另一图库。外部来源保存可回看的帖子地址，不把过期CDN签名当稳定照片身份。

## 实现边界

复用 prepare_import/commit_curation/cancel_curation 的候选模型，新增宿主链接解析与暂存能力。平台网页在独立无痕 WebView 加载，不注册产品图库IPC；仅通过受限、随机会话回传取得精确帖子媒体列表。Instagram按code匹配及轮播总数校对，小红书按目标笔记与正文完整轮播验证，排除头像、推荐、评论与重复节点。图片下载限定平台CDN、响应时间/体积/像素并真实解码；保留平台提供版本，不改写图片规格或静默降清晰度。登录页、验证码、空白或不完整媒体列表明确失败，不伪造成功或只返回封面。首版支持静态图片帖子，混合视频/不支持内容明确说明。

## 验收

功能：候选期间图库零新增、取消零新增、选择子集只提交所选、顺序保持、相簿满额取舍、策划上限、模特与画册引用、原件及其他关联不变、切库/关闭/失败清理。Rust定点测试与类型/生产构建覆盖新提交边界。

真实原生：使用隔离图库，验证已通过调研的5图小红书与NASA双图Instagram，分别只选子集与取消；四个入口覆盖本地和链接，画册同时检查创建与已有画册添加。检查宽/窄窗口、键盘、焦点、加载/异常与取消无残留，并保留截图与数据核对。照片优先、完整构图和统一控件是高级感与质感依据，自动检查不替代原生设计验收。Windows和未实测平台能力另记边界。

## 2026-11-04 实施与验收结果

四个入口已接入共享 PhotoSourceDialog；本地与链接使用相同候选、选择、提交边界。后端 link_import 模块负责单帖识别、独立原生 WebView、媒体完整性检查、下载与候选清理，提交复用原有取舍事务。画册同时覆盖创建及已有草稿追加，策划保留已有参考对象及意图。

通过 Avenil 运行独立 `app.foliune.import-review` macOS debug 应用，图库与用户日常数据隔离。宽窗1320×880、最终窄窗960×800；最终前端资源 `index-BDZr8dZY.css` / `index-BnOZbhwP.js`。真实操作与只读数据证据保存在 `.build/verification/photo-source-import/`。
