# 拍摄策划

## 本轮方案

面向以人像为主的拍摄准备：在桌面撰写并保存策划，拍摄前阅读、修改，导出一张 PNG 长图供手机现场查看。档案属于当前图库，不增加云服务、AI 或移动端功能。

顶部增加「策划」。首页以留白充足的条目组织标题、拍摄日期、地点与概念摘要，新建入口复用深色 `button`。打开已保存策划首先进入阅读，编辑是明确操作；新建直接进入编辑。阅读正文采用有节奏的标题、元信息与章节，参考照片保留原比例、完整构图；编辑以同样的章节顺序组织表单。沿用当前连续中性深色系统玻璃与既有控件，不增加大面积底板、装饰色或跨模块全局样式。

内容包含标题、创作概念、拍摄时间、地点、团队、服装造型、灯光与器材、镜头清单和现场备注。仅标题必填，阅读与导出省略未填写章节。参考图复用图库选片器，最多 24 张，按选片顺序保存；编辑时可用前移/后移按钮或 Alt+方向键调整，移除仅解除策划引用。

保存、删除和导出期间禁用重复提交、编辑与工作区导航、关闭窗口；未保存编辑复用 App 的离开/关窗保护，策划内部返回提供继续编辑、放弃、保存并返回。取消系统导出对话框不显示成功；读取、保存、删除与导出失败保留已有内容并明确报告。删除需确认，保留图库照片与原件。读取失败提供重试，不当作空列表。

长图使用独立 Canvas 排版，固定宽 1080px、浅中性纸张与深色文字，不取 DOM 截图，不更改应用或画册样式。标题、元信息、已填章节及按顺序排列的原图均进入成片。先等待字体与全部原图解码，再按实际换行与图像比例测量高度；中文、英文长单词、显式换行与空行均完整保留。高度超过 32768px、像素超过 4000 万或 PNG 超过 64MiB 时明确要求缩减内容，不截断或静默降采样。任意原图缺失、解码失败、Canvas 编码失败均拒绝整个导出。

## 验收依据

- 独立测试图库：新建、保存、重开、编辑、取消、搜索、删除确认与持久化；切库不沿用旧库状态。
- 未保存时内部返回、顶部导航与窗口关闭保护；保存和导出忙碌期间重复操作和导航被阻止。
- 横竖混合真实照片：选片上限、顺序调整、移除、缺失记录/文件，阅读与导出保持完整构图。
- 宽窄窗口及长内容首段、中段、末尾：标题层级、留白、正文可读、工具可达；键盘焦点、Tab、Alt+方向键、弹窗 Escape。
- 长图检查真实 PNG：中文英文、长单词、空行、完整图像、无截断；取消不报成功、失败保留编辑；超长明确拒绝。
- 类型检查和生产构建只证明静态结构与可构建性。原生系统玻璃、桌面交互、真实照片、导出视觉与手机阅读效果须分别记录实测证据，不由代码通过推定。
