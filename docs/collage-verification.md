# 拼图验收记录

本轮范围：相簿选片进入拼图，自适应、网格与长图，调整后选择相簿保存为新照片。方案见 [拼图方案](collage-plan.md)。功能与设计分别判断，不将构建或静态截图视为动态交互通过。

## 验收环境与材料

- 使用独立 identifier `app.foliune.collage-review`，由 Avenil 管理，不操作生产图库。
- 从已有独立摄影验收库以只读 SQLite backup 创建尚未运行的验收副本，再复制 65 张测试摄影原件及缩略图；仅离线修改新副本路径。
- 原始照片包含横、竖、方形摄影；复制时记录全部原件 SHA-256。证据目录为 `.build/verification/collage/`，隔离依据为 `isolation-before.json`。
- 原生验收前重新构建本轮 release，记录资源版本。Windows 未实测。

## 检查范围

| 项目 | 检查依据 |
| --- | --- |
| 入口与返回 | 多选至少两张进入；右键对象范围明确；返回保留选片与滚动 |
| 三种布局 | 自适应及长图完整构图；网格填充与完整显示、裁切位置清楚 |
| 编辑 | 画幅、间距、留白、背景、排序、补片、移除、交换、撤销与重做 |
| 宽窄窗 | 主要预览、工具、底部选片与主操作可达，照片不受外壳材质污染 |
| 保存 | 同图库相簿、来源默认、新建、名称、实际尺寸；输出与预览一致 |
| 取消与异常 | 退出保护、取消保存/取舍保留编辑，失败可重试，处理期间不串导航 |
| 容量 | 满额取消不提交；确认遵循统一取舍；新图占一个名额 |
| 数据 | 稳定 ID、原件不变，重启后新照片与相簿关系仍可用 |

## 限制

- 非零滚动恢复未完成原生验证：原生自动化在窗口放大后的滚轮/边缘拖动命中失败；首屏返回与目标成片定位已验证。实现和独立代码审查已覆盖保存/恢复滚动逻辑。
- 当前图像链路沿用 `image 0.25.2`，没有ICC色彩空间转换；PNG无损编码不等于广色域颜色保真。65份样片均无ICC，P3/Adobe RGB或混合ICC照片的预览/输出颜色一致性未通过验收，不能声称支持完整宽色域工作流。
- 本轮没有实测Windows、正式签名分发、系统减少动态效果或大图库/100张原生性能。不用静态截图证明完整动效流畅度，也不把Rust测试的失败注入称为已操作全部原生异常路径。
