# 产品约定

## 品牌与定位

- 名称：Foliune。
- Slogan：For photographs worth returning to.
- 面向资深摄影爱好者和摄影师，以画册和欣赏为核心；“高级”与“设计感和质感”为最高产品与设计原则，执行门槛和推进顺序见 [项目代理规范](../AGENTS.md)。
- 完全免费、计划开源；许可证待确定。
- 当前交付 macOS 和 Windows 桌面应用。Android、iOS 不属于本轮实现范围。

## 已确认的技术与交付方向

- 桌面技术栈：Tauri 2、React、TypeScript、Vite。
- UI 使用 Tailwind CSS 4 和 CSS 变量；动效使用 Motion，Radix 按需引入。
- 采用 beUI 的公共 MIT 组件，不引入 Pro 组件；保留所用组件要求的许可声明。组件许可不代表本项目的开源许可证已确定。
- 设计方案先于重要界面与交互实现，每轮同时交付设计质量与真实业务能力；范围和排期服从上述两条基调。不能以原型、静态页面或 mock 代替功能交付。
- 应用免费，计划开源；正式项目许可证与发布签名身份仍待确定。

## 已确认的产品范围

1. 摄影收藏：真实照片导入、分组、数量上限、标签、文字和区域标注、来源记录和搜索；支持查看废弃照片。
2. 我的作品：组织自己拍摄的照片，按时间、地点或项目浏览；与收藏共同作为画册选片来源。
3. 文件管理：导入逐项报告成功或失败及原因，缺失文件可重新定位；重启后照片与元数据仍可用。
4. 画册：从两个图库选片、排序、章节、模板自动布局、手动编辑、阅读和数字导出；重新排版保留已有手工版本。
5. 应用内欣赏：从分组或画册播放照片，提供播放/暂停、前后切换、播放顺序与循环等策略，可选择本地音乐。
6. 可选 AI：用户配置自己的 API Key，支持 DeepSeek、OpenAI、Claude 接入；依据所选模型实际能力限制文本和图片操作。没有 Key 时图库、画册、欣赏和备份仍完整可用。
7. 数据备份与恢复：备份照片、图库关系、标注、画册和必要设置，支持恢复到新库；排除 API Key。
8. 人像模特：维护姓名／昵称、联系方式、城市、风格标签、备注、性别（男／女）、生日，以及有序样片与封面；档案属于当前本地图库。首页每行一位，左侧基础信息、右侧最多三张等高原比例样片；优先同构图方向，不足时竖左横右分组，包括空档案均保持固定行高，规则见[横向档案行](model-overview-rows.md)。点击进入只读详情查看已填资料和全部样片；详情与编辑均为紧凑资料卡置顶、样片在下方全宽展示，不显示“基本资料”“样片”分区标题；点击编辑后修改（见[资料置顶](model-profile-top.md)）；保存回到更新后的详情，新建取消回列表，已有档案取消或放弃修改回详情。编辑提供取消与保存，删除仅在列表删除图标及详情页头提供，进入统一确认后删除档案；编辑页不提供删除。浏览流程见[模特浏览与详情](model-browse-detail.md)。
9. 社交排版：从相簿选择照片后通过「模拟排版」进入，临时预览微信朋友圈多图动态、小红书图文笔记、Instagram 多图帖子。固定本地头像和昵称，按平台提供朋友圈文案、小红书标题／正文、Instagram 配文，三个平台平铺单行选择。排版不设独立顶部导航，不保存或提供草稿，退出直接结束；不包含导出或平台发布。

模特与社交排版的原始方案见 [模特与排版](models-social-plan.md)，临时预览最新约定以 [仅模拟预览](social-preview-only.md) 为准。模特性别以与风格标签一致的按钮直接单选，再点取消可恢复未填写；不要求手动输入。模特风格标签采用常用标签平铺点击多选，再点取消；选中不显示勾号；在标签末尾的管理图标打开弹窗，管理当前档案的全部可选标签，预设和自定义均可删除。可选目录与已选值分别随档案保存；明确清空目录后不自动恢复预设，未选的新标签也可保留，不使用下拉。身体资料不再提供编辑，历史字段不做批量清理。规则与验证见[模特风格标签](model-style-tags.md)。模特样片引用图库稳定照片 ID，删除档案或移除样片不删除照片，不改变相簿或画册。模拟排版仅在内存中使用照片 ID，照片使用三列以上无文件名缩略图网格，直接拖动图片插入排序，右侧预览同步并按可用视区适配；支持键盘 Alt+左右逐张、上下按行调整。长文保留右侧局部滚动查看全文。平台切换保留完整选片及文案，小红书标题不串入其他平台。超过当前模拟数量时明确说明仅预览前 N 张，保留全部选片。平台显示裁切不修改原件；预览是布局模拟，不承诺与各版本客户端像素一致。

数字导出本轮采用可独立打开的自包含 HTML，界面明确标注格式。原有约定没有 PDF 硬要求，本轮不以 HTML 冒称 PDF。云同步和系统屏保插件不属于本轮范围，欣赏是应用内功能。

## 必须保留的规则

- 图库照片墙的临时选择只用于后续操作，不直接改变相簿关系、画册或原件；它与候选池的业务取舍独立。
- 废弃状态属于照片与分组的关系，只影响当前分组。
- 废弃照片仍可访问，默认不主动展示，不占该组有效名额。
- 废弃不得删除原文件、影响其他分组或改变已有画册。
- 满额时把新照片和原有照片一起取舍，确认前不提交变化。
- 取消新照片表示不加入；取消原有照片表示从当前分组废弃。
- 以上“取消照片”指在候选池中取消保留该照片；关闭或取消整个取舍对话框表示不提交任何业务变化。
- 恢复废弃照片、降低分组上限同样受容量约束；需要取舍时使用统一候选池，确认前不提交恢复、上限或成员状态变化。
- 候选池确认是一次原子业务提交，失败不得出现部分新增、部分废弃或上限提前变化。
- 画册重新排版应保留已有手工编辑版本。
- 区域标注随照片保存，按图像坐标定位；缩放展示或重启后仍对应同一图像区域。
- 文件缺失、导入失败、导出失败、恢复失败及 AI 请求失败应明确报告，不能静默伪装成功。
- 备份恢复后不依赖旧机器的原文件路径；恢复失败应保留现有可用库。Key 不进入备份、普通业务导出或日志。

## 视觉方向

视觉方向与 UI 开发、验收依据统一见 [设计规范](design.md)。该规范取代此前“中性浅色工作区、黑白灰控件”的样式方向；历史截图和验收结论不代表已达到新规范。以照片和画册为中心，工具按场景出现，不强制使用永久侧边栏。支持窗口缩放、键盘操作及系统减少动态效果偏好。

相簿与画册卡片单击打开内容，右键管理；卡片获得焦点后可用 Shift+F10 或菜单键打开同一菜单。相簿信息及删除、画册重命名及删除通过该菜单访问，卡片不常驻管理按钮，新建入口保留。右键不打开内容，不改变照片选择；删除须确认。未归入相簿为虚拟集合，不提供重命名或删除。规则与验收见[卡片管理](card-management.md)。

相簿封面采用一致的陈列比例与标题/数量层级，照片墙仍完整呈现原作品。照片墙默认处于浏览模式，悬停不显示选择框或照片三点入口；普通单击打开已有大图预览，不改变选择；照片详情仍从右键菜单访问。大图预览为查看界面，承担观看、缩放拖动、左右切换和返回，不显示选择框、已选计数或通过空格改变照片墙选择。返回按钮保留左上位置，右上信息图标与其共用窗口控制所在高度的顶部单行，并为系统控制保留安全槽。默认不显示照片名称；点击信息图标按需展开深色小浮层，显示当前已展示照片的名称、不同于名称的原始文件名、有效尺寸，以及已有的有效拍摄时间、地点与来源，不为展示信息新增文件读取。左右切换及页码位于图片下方独立的底部工具行，不覆盖照片；照片在扣除顶栏与底部工具行的舞台内按原比例适应窗口。返回按钮默认无底色、边框及阴影，保留轻量悬停、按下与键盘焦点反馈。静止约2秒后隐藏自定义顶部及底部工具，移动指针或键盘操作唤醒；工具栏悬停、键盘焦点及信息展开期间保持可操作，隐藏时保留顶部及底部工具行占位，前后照片位置和尺寸稳定。信息可再次点击图标、点击外部或按Escape关闭，切图时关闭；信息展开时第一次Escape仅关闭信息并返回触发按钮，后续Escape退出大图。照片操作通过桌面右键菜单及键盘菜单入口访问。右键选择第一张照片后进入选择模式，其他照片显示选择反馈并可单击增减选择；清空最后一张、取消选择、Escape 或切换相簿后恢复浏览模式，单击恢复打开大图预览。批量操作栏保留更多入口；对已选照片操作时批量范围明确，对未选照片操作时只针对该照片，不借用其他已选项。布局与简短命名承担说明，避免重复教学、文件信息和悬浮工具覆盖作品；必要空态、错误、风险确认及可访问名称保留。

大图切换提前准备当前目标与相邻原图，等待时保留已显示照片，实际展示节点可显示后再交接；标题和页码与可见照片一致，快速切换以最后请求为准。正常切换不闪出加载文案，持续等待与失败保留必要反馈。过渡采用短促淡出与轻微方向位移，减少动态效果时直接交接；照片保持完整比例，不依赖动画完成决定可见性或退出。实施与验收见[大图切换](photo-review-transition.md)及[顶部单行工具栏](photo-review-titlebar.md)。

大图查看支持围绕指针滚轮缩放（适合窗口的1–8倍）、放大后左键拖动、双击照片在2倍与适合窗口之间切换。只作用于照片实际像素区域，边缘留白及顶部窗口手势独立；边界按实际图片尺寸约束，新显示照片或原图地址变化恢复适合窗口，同照片缩略图升级原图保留视角。滚轮合并连续输入并短促平滑收敛，首输入立即反馈、反向立即改向；拖动直接响应，双击用短促柔和过渡，动画中可反向双击或用滚轮、拖动从当前画面接管；减少动态效果时立即完成。不更改原文件或保存裁切。实施与验收见[大图缩放与拖动](photo-review-zoom.md)。

实施阶段与可验证验收场景见 [implementation-plan.md](implementation-plan.md)。清单完成状态必须依据实际代码和验证证据更新。


## 相簿拼图

在相簿（含未归入相簿）中选择至少两张照片，经批量操作栏或右键「拼图」进入独立工作台，不增加顶部导航。选片仅来自同图库；工作台提供大预览、右侧布局工具与底部选片条。自适应与长图完整呈现原构图；网格可按照片独立等比裁切、拖动和缩放，支持恢复完整显示，均不改源文件。画布拖动交换与底部拖动插入分工明确，底条提供交换及 Alt+方向键替代，裁切状态用方向键调整位置。布局、选片、排序、裁切与背景均可撤销/重做。

拼图为新的无损PNG照片。默认输出尺寸保留每张来源的有效像素密度：完整显示按全部原图计算，裁切按缩放后的实际取景区域计算；小尺寸来源不得拖低其他照片的清晰度，必要的等比放大不代表新增细节。预览参考尺寸不限制成片像素。保存时可锁比例显式调整长边，降低时显示「已降低分辨率」并提供恢复原图尺寸入口。单边最多32768px，总像素最多1.6亿，最多100张；默认结果超限时仍可打开保存对话框，明确要求调整布局、选片或主动修改输出尺寸，绝不自动降低清晰度。不能表达为有效像素矩形的组合明确报错，不重叠或静默裁切。保存对话框含名称、实际像素、同图库相簿封面与搜索、新建入口，默认来源相簿。新建是显式创建相簿操作，之后取消成片保存不会删除已创建的空相簿。

保存通过统一候选取舍：未满额直接原子确认，满额时由用户取舍，取消不改变照片或相簿关系，失败保留编辑。候选中须保留生成拼图才能提交；取舍废弃只影响目标相簿关系，不改原件、其他相簿和画册。返回或导航有未保存保护，生成、创建相簿及取舍期间阻止导航和窗口关闭。成功返回原相簿并保持滚动和仍有效的选择，仅在右下角浮动提示「保存成功」，约3秒自动消失；不占照片墙布局、不抢焦点，不再提供相簿名、查看或关闭入口。方案与本轮验证范围见[相簿拼图方案](collage-plan.md)。


## 拍摄策划

「策划」为独立顶部工作区，属于当前本地图库。内容由简短拍摄概览、整体视觉、拍摄场景、执行准备组成。概览交代主题、方向、时间地点、出镜团队和成片用途。内部Part对应界面的场景，每个场景为独立卡片：单层中性深色浅底、可见细边界和克制圆角，紧凑标题与要点；卡内以“参考图”“拍摄参数”“镜头清单”三个短标题明确分区，上区图与参数并排、下区全宽文字清单。光影、镜头焦段、场地、造型、情绪及时间直接可见；阅读与编辑均不设展开收起。图片保持完整构图，参数统一单列标签和值，不随参考图数量分散为多列。镜头条目纵向组织，避免多层章节与零散表单。

全案概览保留“拍摄时间”，交代整组日期或整体安排；各场景复用独立`timeWindow`为“拍摄时段”，在各场景标题旁展示并在同处编辑，作为场景一级阅读信息；长标题或时段空间不足时完整换行，拍摄参数区不重复显示。长图同步标题旁时段布局。支持自由填写时间范围及简短时段说明，页面阅读、编辑、搜索与长图一致；空项阅读省略，不根据全案时间推导各场景时段或自动计算光线。

整份策划的妆造、道具、器材为全案固定准备，在整体视觉之后、首场景之前以“整组准备”统一列出，支持阅读、编辑、搜索、保存、备份和PNG；空内容阅读时不占区域。旧全案缺字段时补空，不猜测拆分旧场景造型。已有场景造型与道具文字原位保留、可读可改，新场景不重复提供空造型字段。

场景可选1–3张参考并逐图填写参考意图；0张允许保存未完成草稿。新保存最多3张，错误指出具体场景。历史超过3张时完整读取、恢复、显示和导出，编辑提示整理，不截断或静默丢图。图片仅在场景参考区展示与编辑；全案和镜头级旧图片在页面及长图中不再展示，也不提供这些层级的选图入口。旧引用及意图仍保存在文档与备份，不自动搬迁或删除；非空旧意图作为对应整体视觉或镜头拍法中的纯文字参考要点保留。

每个场景通过有序结构化镜头条目组织拍摄内容，不再提供自由文本“补充／补拍清单”的填写入口、阅读显示、搜索命中或PNG导出。旧`part.shotList`原文仍随保存、复制和备份保留，不迁移、猜测拆分或清除；没有结构化镜头时显示“暂无镜头”。镜头按逐条纵向组织：名称与优先级同排，关键拍法作为主正文紧随，镜头内容收拢到固定阅读宽度；构图/姿态/光线/情绪在下方统一单列标签和值，参考要点使用同一标签起点并降低视觉重量；阅读仅显示已填内容，编辑保留全部结构化字段。场景共同参数与镜头独立拍法分别保留，不按语义猜测合并或删除内容。旧参考要点置于对应镜头末尾，以文字显示，不插入图片。参考和镜头均保留独立稳定ID，同图跨位置说明独立。

场景、镜头、参考可排序及移除，删除含内容的场景或镜头须确认。移除参考或删除策划不删图库照片、不改相簿和画册。每份策划最多20场景、100结构化镜头、120参考条目。旧数据全部保留：旧v1的造型/光线/镜头清单进入「原拍摄安排」对应字段；已存在v2缺镜头清单或焦段字段时补空，不根据既有拍摄要点猜测或改写内容；旧有图片顺序、策划ID及时间保持。

阅读与编辑分开；保存失败保留输入，内部返回、导航与原生关闭保持未保存保护，保存/导出及切库期间阻止离开和重复操作。

长图为独立1080像素宽PNG，采用连续中性白色纸面与章节排版：全案概览、只出现一次的整组准备、逐场景章节、执行准备。取消长图灰底沟槽、卡片圆角与描边，统一单层页边距；场景以浅细线、编号、标题及相邻时段建立边界，章节间距大于内部间距，应用内的场景卡片保持。妆造、道具、器材在首场景前按单列标签和值统一列出；每个场景按标题要点、参考图、拍摄参数、纯文字镜头清单组织，三区标题清楚，镜头文字及非空旧参考意图完整导出，图像仅来自场景引用。长图参考图最多两列；三张时第三张保持半列宽续行，历史超限图片完整续排，保持原比例和列内图文关系。正文40px、图注及标签36px，以手机缩放阅读为依据；缺图或解码失败明确拒绝，不静默漏项。单边最多32768像素、总像素最多4000万、文件最多64MiB，超限明确要求调整，不截断或降采样。取消保存对话框不报成功。导出供手机查看，不包含自动同步、现场打卡或移动端服务。
