# 策划阅读重排

本轮依据用户对场景拍摄板的反馈：参考图只放在场景内，镜头清单不重复图片；提高密度的同时，优先让读者迅速辨认各个场景与其中的拍摄安排。

## 场景与视觉方案

沿用统一中性深色和连续系统玻璃背景，不新增底板、装饰色块、折叠或导航。通过稳定对齐和节奏组织三个层次：

1. 编号、场景标题及紧邻的一句拍摄要点。标题保留明确层级，场景之间约 24px 留白和极弱分隔。
2. 二、三图的上区为约 2:1 两栏；单图采用 300px 参考列与剩余参数区，参数区按两列紧凑排列，避免单图仍占据宽参考区形成空带。左侧仅放场景参考图及逐图意图，右侧从图片顶部开始排列光影、焦段、场地、造型、情绪与时间。图片舞台约 170px，保持原比例和完整构图、左对齐；单图的意图紧邻图片，历史超过三图仍全部显示。没有参考图的阅读场景只显示已有参数，不保留空图片栏。
3. 下区为全宽镜头清单。镜头序号与名称、关键拍法、构图与姿态、光线与情绪使用固定对应列；名称列限定150–190px，其余列按内容分配，不因空列移除而让名称列膨胀；每项全文可见，避免细节形成散落的标签串。窄窗保留顺序，改为纵向成组行，不缩小字号或隐藏内容。

全案概览进一步收紧标题、构想和元数据间距；整体视觉只保留文字。参考图的添加、排序、移除与意图填写均留在场景。镜头和全案的旧引用数据原样保留，不迁移、不清理，不改变保存契约、引用并集或图库照片。

全案和镜头已有参考意图作为紧凑的纯文字「参考要点」保留，镜头放在拍法列中，不新增空列或图片入口。某一细节组在整个场景中均未填写时，阅读态不保留空列；编辑态展示全部字段。列表参考数仅统计场景图片，与页面实际显示一致。

## 编辑与状态

编辑沿用同样的场景上区和镜头列组织。场景参数、拍法及全部细节直接编辑，不新增开关或折叠；已有排序、删除确认、保存失败与未保存保护继续生效。图片缺失明确显示，空场景与空镜头清单保留必要反馈，键盘排序和焦点能力保留。

## 验收依据与限制

- 检查一、二、三张以及历史多图场景：图片完整、图文相邻、参数顶部对齐，镜头与全案不出现图片或选图入口。
- 检查多场景和长镜头描述：标题位置稳定，名称、拍法和细节对应清楚，场景间节奏区别于场景内部间距。
- 宽窗与窄窗分别检查阅读和编辑；全部已填字段可见，长文本不溢出、不互相挤压，操作可达。
- 类型与构建只能证明结构有效；实际照片、原生窗口、保存与键盘路径由本轮独立桌面验收记录判断，不以静态代码声称视觉已通过。

本方案以摄影参考和清晰的执行信息构成品质，不依赖装饰效果。图片仍优先获得空间，但不再把参数和镜头清单挤到下一整屏。
