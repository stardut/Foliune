# 实施计划与验收清单

更新日期：2026-10-29。此文档同时记录已批准实现范围、实现完成项和实际验收边界。产品语义以 [product.md](product.md) 为准；本次 Tauri 2 决策覆盖旧文档中的 SwiftUI 路线。

## 交付边界与证据规则

- macOS / Windows 桌面；Tauri 2 + React + TypeScript + Vite，Tailwind CSS 4 + CSS 变量，Motion，beUI 公共 MIT 组件，Radix 按需。
- 免费、计划开源，项目许可证待定；不使用 beUI Pro。
- 全部业务使用真实本地数据，先功能后视觉动画。测试替身只用于隔离测试，不能替代实际文件导入、持久化、导出与恢复。
- 本轮包含收藏、作品库、标注搜索、分组容量取舍、画册全流程、应用内欣赏、本地音乐、可选 AI、备份恢复；不包含云同步或系统屏保插件。
- 数字导出为自包含 HTML，界面说明具体格式；没有 PDF 硬需求，不将 HTML 标成 PDF。
- 每个勾选项须有实际验证证据。最终报告分别说明自动检查、桌面实测、外部 API 实测、Windows 实机验证；没有 Key、目标系统或网络时如实记录未验证项，不伪称通过。
- 本地服务运行、启动、停止和日志检查由 Avenil 管理；不创建 worktree，不 commit 或 push。

## 共享业务契约

| 对象或操作 | 契约 |
| --- | --- |
| 照片 | 稳定身份独立于分组；记录实际照片文件、收藏或作品属性、标题、时间、地点、项目、标签、文字/区域标注和来源。缺失文件可重新定位，不能靠删记录隐藏问题。 |
| 分组成员 | 以照片与分组的关系保存有效/废弃状态；同一照片在不同分组相互独立。废弃不删除文件，也不影响画册。 |
| 候选池 | 包含当前有效照片与本次新增/恢复候选；明确区分未选的新照片与旧照片。确认前仅暂存选择，取消不修改业务库。 |
| 容量提交 | 校验所选有效数不超过目标上限；新成员、旧成员废弃、恢复和上限修改作为同一次事务提交，失败整体回滚。 |
| 区域标注 | 保存图像坐标及标注内容；显示缩放不改变标注定位，重启和备份恢复后可编辑。 |
| 画册 | 引用稳定照片身份，独立保存顺序、章节、模板布局和手工编辑版本；分组关系变化不联动改画册。 |
| 重排 | 生成新的自动布局版本，保留可访问的已有手工版本；禁止原地覆盖手工成果。 |
| 导出 | 一个自包含 HTML 文件，包含阅读所需照片、布局与样式；不依赖开发服务器、应用私有路径或外部网络。 |
| AI | Key 可选；提供商、模型和能力分别处理，不把提供商名等同于支持图片。错误清楚呈现，不能以假结果替代失败。 |
| 备份 | 包含恢复所需照片和业务数据及版本信息，排除 Key；先验证再恢复，新库恢复不得依赖旧路径，失败保留现有库。 |

存储实现、支持的照片格式、具体模型和模板数量可由实现选择合理默认，但需明确展示真实能力，不擅自删除上述功能或增加静默回退。正式许可证、签名、公证和发布身份不在实现中默默确定。
