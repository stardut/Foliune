# 大图切换加载与过渡（2026-11-02）

## 场景与方案

用户要求解决大图切换中“读取图片…”打断观看，并加入符合设计规范的切换动画。现有 PhotoReview 以照片 ID 为 key 挂载共享 PhotoImage；组件每次 pending 从 true 开始，原图读取时立即显示加载文字。当前切换也没有照片过渡。

保持当前深色、控件、字体、完整构图和查看模式。限定改进大图展示，不连带改照片墙、画册纸张或播放器。

- 提前准备相邻照片，等待新照片可显示前保留当前作品，避免每次显示加载文案；仅对持续等待给出轻量状态，失败和缺图保持明确可操作。
- 新图在下层默认可见，旧图在上层短促淡出，结合约12px的方向位移与柔和减速；不缩放、裁切、模糊或改变照片色彩。视觉过渡约220–280ms，减少动态效果时直接替换。
- 保留有界的相邻原图准备，不解码整库。快速连续、反向切换只显示最后目标；关闭、对象或URL变化后不提交过期加载结果。
- 可见内容和卸载不依赖动画完成；没有从透明开始的关键内容，也不用退出动画阻止切换、返回或清理。保留2.2秒工具栏隐藏、键盘、焦点恢复和窗口手势。

## 验收计划

用独立图库真实混合比例照片，在原生 WebView 看单次与连续切换、首中末、正反向、返回与工具栏隐藏；检查照片完整构图及过渡后无残留。异步加载、失败、重定位URL、对象删除/清空、卸载与减少动态效果由有意义的行为回归补充。构建及静态截图不替代动效检查，记录真实证据与未测边界。

## 实施

正式仅4个文件：PhotoReview 保留原idle/键盘/拖区框架；新增局部 PhotoReviewImage 与 ReviewPresentation，将请求目标与显示帧分离。共享 PhotoImage 未改，照片墙、播放器、画册纸张和图库持久化不变。

- 目标及相邻±1的原图准备，最多3个预载条目；淘汰不改变已经显示的DOM图片src。
- 首次打开可用缩略图承托。实际 incoming img 的load和decode完成后交接，不仅依赖分离的预载Image完成。等待超过350ms才显示角落轻量状态，无常规读取文字覆盖。
- 同一父节点中的keyed图层最多2个：准备时旧图全舞台背景遮挡新图，交接时新图默认opacity1、方向位移12px，旧层淡出240ms。定时直接移除旧层，不靠animationend/exit，关闭直接卸载。旧层及准备层aria-hidden、inert且不接收指针。
- 快速切换以同步请求ref推进，加载回调校验代次与目标；URL/availability变化、缺图、读取失败、重新定位、删除目标、清空和卸载均有对应处理。减少动态效果时不保留视觉退场。

## 实际验证（2026-11-02）

类型检查、Vite、macOS release Tauri `.app` 构建通过，资源 `index-D9eiwmpl.css` / `index-BWFt4zAR.js`；仅既有api.ts动静态导入分包提示。Avenil管理“Foliune 深色设计验收”，原生实例 `app.foliune.dark-review`，独立65张真实混合比例摄影、4本相簿，2640×1760截图像素。

行为回归：`.task/review-presentation-check.mjs` 验证实际异步控制器资源链；`.task/review-hook-check.mjs` 验证实际hook StrictMode重放与JSX DOM事件交接；既有 `.task/photo-review-viewer-check.mjs` 继续验证idle、Tab同步唤醒、查看模式、连续请求及实际Tauri drag.js路径。包括晚到成功/错误/DOM decode、反向连续切换、URL/availability/relink、3缓存/2层、延迟状态、减少动态效果、删除/清空/关闭与清理。

原生操作：

- 首张打开与单次前进，照片、标题、页码一致，未出现读取文字。
- 第4张起点快速Right×3再Left，最终6/65；继续Right×70停65/65，下一张禁用；Left×70回1/65，上一张禁用，无环绕或错图。
- 工具栏静止后AX隐藏，Tab重新显示；切换后立即Esc回照片墙，预览无残留。中途用户在实际窗口自行浏览到第19张，与反馈时间重叠，该变化不作为自动操作结果。
- 用户实看后明确回复：**“切换自然，未见加载文字”**。此为本轮原生动态观感反馈。

证据目录 `.build/verification/photo-review-transition/`，有initial/rapid/last最终画面、forward/quick截图序列及采样时间。工具的第一帧采样约430–540ms才返回，超出240ms过渡，截图序列未捕获动画中间帧，不拿静态最终画面证明动效。构建前尝试的before序列没有得到可靠切换结果，不作为通过依据。动态观感依据用户上述实际反馈；状态及清理依据原生操作、源码和独立回归分别判断。

限制：本轮未在系统设置中实际切换“减少动态效果”，未用真实缺失或损坏原件制造失败，未实测重定位；这些通过异步行为回归与源码验证。未复验窄窗及Windows，不将本机65张样本操作当成通用内存/FPS性能结论。未修改真实照片原件、图库关系或画册。

本轮通过提前准备、稳定交接和短促克制的空间过渡保持作品观看连续；完整构图与默认可见优先于动画。用户认可本次切换观感，不据此宣称整套应用设计已全面验收。

独立验收结论：最终源码、控制器异步回归、hook重放与JSX事件回归、既有查看器/idle/Tab/实际Tauri拖动回归均独立检查通过，未发现确认需返修项。实看首张、快速切换终态和末张代表图，未见读取文字、叠层残留或构图变形。动态观感采用用户本机反馈，不以未捕获中间态的静态图冒称完整动效验证。
