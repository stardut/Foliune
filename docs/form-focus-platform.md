# 控件焦点与平台平铺单选

> 后续变更：Instagram 主页已按用户要求移除，当前为三个平台单行，见[仅模拟预览](social-preview-only.md#2026-11-02-三个平台单行)。本页四项两列为当时实施与验收记录。

## 2026-11-02 需求与方案

用户指出输入框和选择框获得焦点后的白色外框过重，要求检查全软件同类问题；模拟平台改为平铺单选。

审计发现全局 `:focus-visible` 同时给按钮及所有表单控件绘制 2px 近白轮廓并向外偏移 3px，表单不受现有鼠标输入模式保护，因此鼠标编辑也会形成外圈。搜索容器另有近白边框与 3px 光晕。应统一优化焦点体系，不能只修模拟页面或用全局禁用焦点掩盖问题。

设计方向：表单沿已有边界或内缘表达输入焦点，使用中性灰蓝细线，去掉高亮粗白外圈；键盘聚焦仍明确可辨，按钮及离散选择控件沿用真实输入模式判定。搜索组合控件只显示一处焦点反馈。照片多选、候选保留、区域标注及画册纸张的业务边界单独判断，不误当作输入焦点删除。

平台以四项平铺的原生单选组直接展示，窄左栏采用稳定的两列布局，label可点击，选中状态与键盘焦点分别可辨。保留平台 key、文案和临时选片状态，支持 Tab、方向键及 Space。样式局限控件，不污染浅色平台画布或画册纸张。

验收范围：全 `src` 样式／组件焦点检索与覆盖关系审查；原生模拟的单选、文案／标题、按钮和键盘路径，搜索、模特资料及设置中的代表输入和选择控件；宽窄窗、鼠标编辑、键盘焦点以及返回后的无残留。按改动运行类型和生产构建，后端无变更则不重跑 Rust。

## 样式审计及实施

统一 `--focus: #91a2b5` 和 `--focus-border: #708398`。文本、数字、密码、textarea、select 沿已有 1px 边框表达 focus，键盘输入适当提升边框明度；按钮、summary、checkbox、radio、range 与 tabindex 采用 1px 键盘焦点，并复用现有输入模式识别。搜索仅在容器上改变边框，删除原 3px 光晕。选择栏专属 2px 焦点改为细线。

| 审计范围 | 同类问题及处理 |
| --- | --- |
| 相簿创建／编辑、照片详情／区域说明、候选容量 | 复用全局输入规则，去除近白外圈；不改业务和输入值。 |
| 画册创建与编辑侧栏、模特资料、AI及备份设置、欣赏参数 | 输入／select及离散控件继承统一焦点；不改画册纸张或导出CSS。 |
| 搜索页、模特搜索及共用选片搜索 | 原白边与光晕改为单个容器边框；内部输入不叠框。 |
| 导航、普通／图标按钮、批量操作栏 | 键盘统一细灰蓝定位，鼠标或相应程序恢复无外圈；专属1px规则继承新色。 |
| 图库与审片控件 | 已有1px键盘焦点继承新色，不改照片像素及查看区域。 |
| 共用PhotoPicker | 外侧多选边界与内侧键盘定位分离；避免鼠标聚焦已选项时被全局规则吞掉业务边界。 |
| 模拟平台 | 四个原生radio改2×2平铺，每项至少36px点击区，实心点与表面表示选中，键盘细边表示焦点。 |

保留有明确职责的边界：图库照片多选、候选保留、画册选片和纸张编辑选区、区域标注的白／灰边、照片勾选框、浅色主按钮与导航及控件材质高光。它们表达业务选择或材质，不属于误加的输入焦点白外圈。

## 验证结果

本轮只改 `theme.css`、`index.css`、`components/photo-picker.css`、`SocialWorkspace.tsx`、`social.css`。`pnpm typecheck`、含 TypeScript 的前端生产构建、macOS release 独立验收包与标准 `Foliune.app` 均通过。保留既有混合导入与大分块构建提示；无 Rust／数据库变化，没有重复后端测试。

通过 Avenil「Foliune 模特排版验收」运行独立测试库，macOS 15.0.1，约1320×880与922×720窗口。原生实际检查：

- 搜索框鼠标聚焦和 Shift+Tab／Tab 键盘回到输入，容器单细边，无外圈／光晕。
- 模特姓名点击、Tab到联系方式、点击身高数值框，只有原边框反馈；不修改档案。
- 设置中点击空密码框，Tab到已勾选checkbox，焦点和勾选状态可分辨；未输入凭据或保存设置。
- 画册创建对话框的照片来源select，检查鼠标选择后取消及键盘焦点，未创建画册。
- 四项平台默认朋友圈，鼠标点击Instagram主页，Shift+Tab回单选后Left切帖子、再次Left切小红书，Space保持选中，Tab到标题。平台文案与预览同步，正文保留且始终仅一个radio选中。
- 真实三图在宽窄窗检查平铺控件、鼠标textarea和键盘标题输入；没有粗白外框，四项完整可读。
- 共用选片器鼠标新增一项时外侧业务边界保留；Tab再Shift+Tab回到该项，出现独立内侧灰蓝定位线。取消后仍为原三图，选择状态未误提交。

独立代理完成最终代码与14张本轮原生截图审查，未发现需返修项。统一细边反馈减少操作噪声，保持现有材质与明确的选中／键盘路径，满足本轮「高级」和「设计感和质感」的控件实施依据。
