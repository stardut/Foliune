# 悬浮胶囊导航

2026-11-02，按用户要求优化导航栏质感，改为悬浮效果。本轮仅将导航外框由凹入槽改为浮起的深色胶囊；取代[胶囊控件](capsule-controls.md)中导航外槽的凹入方向，其他控件和已认可的字体、背景、相簿卡片不变。

## 方案

摄影浏览、画册与模特页面共用顶部导航。保留紧凑胶囊、浅色选中块与现有液态切换，照片仍是页面主体；通过局部承托与光影建立精细触感，不增加装饰、文案或新的动效。

外框改用上明下暗的中性深色表面，取消上沿内凹暗影，以细顶缘高光和柔和向下投影表达离开背景的层次。内留白由 2px 增至 4px，内段维持 34px，外高由 40px 增至 44px；圆角保持同心胶囊关系。浅色选中面、文字、按钮宽度、鼠标与键盘状态保持，设置和搜索无选中时也由外框自身的表面与投影维持层次。

样式集中在 `.primary-navigation`，不改全局主题变量、页面背景、纸张或导出。导航几何仍由既有组件实测，液态切换不依赖固定内留白。

## 验收依据

- 类型检查与前端生产构建通过；静态核对改动局限于导航表面和内留白，未改变业务与动效。
- 主代理负责真实 macOS 应用及独立验收：宽窄窗口、收藏/作品/画册/模特切换、设置和搜索无选中态、悬停/按下/键盘焦点、液态切换及减少动态效果。检查外框悬浮感、浅选中协调、文字可读与无裁切、遮挡、残留。
- 真实摄影内容与现有背景、卡片协调，不因局部控件提升抢夺作品；构建结果不替代设计通过或用户认可。

## 实现与验证

仅修改 `apps/desktop/src/index.css` 中 `.primary-navigation` 的内留白、边缘、背景与阴影。外框高 44px、内段 34px，保留原有 gap、字体、标签、选中面与液态组件；取消向下照亮的凹槽底色和内凹暗影，改为细顶缘与两层柔和下投影。无 `overflow` 裁切和额外伪元素，焦点与液态表面仍由原规则处理。

2026-11-02，通过 Avenil 一次性服务「Foliune 悬浮导航构建验证」执行 `pnpm typecheck && pnpm build`，类型检查和 Vite 生产构建通过。资源为 `index-DZ-2iegY.css` / `index-DrEC9z4w.js`；构建提示现有 API 混合静态/动态导入及大于 500kB chunk，未出现类型或打包错误。

原生观感、宽窄窗口及动态交互由主代理继续记录，本开发记录不预先声称设计验收通过。

## 第二轮：轻盈通透的悬浮外框

2026-11-02，用户否定首轮效果，认为外框太厚重、原版更好，要求更轻盈通透、自然悬浮。上文首轮方案和验证仅保留作历史证据，不作为用户认可或本轮设计通过的依据。

本轮仍服务于摄影浏览与页面切换，让浅色选中块承担主要操作反馈，外框退为低对比承托。恢复原版 2px 内留白与 40px 外高，内段保持 34px；以中性半透明暗面 `rgba(35, 38, 43, .32)`、`#ffffff10` 细边和 `#ffffff08` 内顶光表达轻微浮起。取消首轮高不透明度明暗渐变、亮边与双层黑投影，只保留一层 `0 4px 12px -5px #00000038` 柔影，降低外框与连续背景的表面对比。

改动仅限 `.primary-navigation` 外框，沿用现有字体、按钮、浅色选中面、焦点与液态切换。背景透光继续来自既有系统材质，不新增图案、模糊、伪元素或动效；照片、卡片、纸张及其他界面不调整。

验收先核对样式范围、类型检查与前端生产构建，再由主代理在真实 macOS release 应用中对照原版与首轮：检查宽窄窗口、有选中与无选中、悬停/按下/键盘焦点及液态切换。判断依据是外框紧凑、透光自然、阴影不形成黑托盘，选中反馈可读，与照片和既有背景协调。静态检查与构建不替代原生观感或用户认可。
