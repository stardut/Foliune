# 作品目录绑定

摄影师在本机或移动硬盘上按拍摄项目整理成片。可在「设置 → 作品目录」选择一个目录，让每个含有可用照片的一级子文件夹成为作品相簿。读取范围是子文件夹直接包含的照片，保留原件位置。绑定照片与手动导入的照片都可以选入画册。

设置中的「作品目录」区说明目录用途，提供绑定、查看来源、更新原目录位置和解绑。点击「选择目录…」直接打开系统选择器，原目录移动后可点击「选择新目录…」选择它的新位置。作品页在未绑定且没有相簿或待同步相簿时，空态在「新建相簿」下方提供跳转到设置的文字入口。同步弹窗沿用中性深色浮层、现有焦点样式和确认按钮。每行只说明新增相簿或目标相簿、照片数量。

## 发现与确认

首次绑定、启动及硬盘重连时检查目录，运行期间监听新增。短时间内发现的内容按来源相簿合并，在图库可安全浏览或设置空闲时用一个弹窗确认。「同步」把每本相簿放进独立任务并关闭弹窗。「忽略」新文件夹会排除整个来源，忽略已有相簿里的新增照片只排除这次列出的文件。忽略结果在重启和硬盘重连后仍有效。

同一块硬盘上的相簿按顺序同步。读取原件、计算指纹及生成缩略图在后台准备，每本相簿准备完成后一次写入索引。相簿之间独立提交，单本失败可重试，后续相簿继续执行。浏览、选片和编辑画册期间可继续操作。删除待同步相簿、调整正在使用的来源等冲突操作须等对应任务完成。

确认时保存每本相簿的任务及选中的文件范围。退出应用后，下次启动时会自动恢复已确认的待同步任务。已提交的相簿保留，中断时正在处理的相簿从头准备，随后一次提交。硬盘离线时已确认任务继续等待，连接后接着同步。明确失败的任务保留原因并由用户重试。随后发现的新文件仍须确认。

来自作品目录的相簿在照片数量后显示文件夹同步图标，待创建的同步卡片也显示该图标。设置说明使用同款图标，卡片悬停和读屏提示「来自作品目录」。解绑后保留已有相簿及其来源标识。排队中的相簿显示「等待同步」。运行中以照片张数和细进度条反馈真实进度。已有相簿保留封面与访问入口，待创建相簿使用同尺寸临时卡片。任务成功后移除进度反馈，失败时在对应卡片显示原因和「重试」。进度文字和状态在减少动态效果时仍可读。

相簿名称可在应用内编辑，识别来源时使用目录身份。删除相簿解除图库关系并排除来源文件夹。没有其他引用的照片退出全局搜索和图库选片，磁盘照片和画册已有引用保留。解绑停止发现，已收录的照片继续引用原位置。主动解绑或换到新的目录路径时，结束旧路径的待同步任务。

## 离线与备份

相簿和画册在硬盘离线时仍可打开。缺图在原有位置显示占位并保留尺寸和构图数据。目录不可访问时提示「作品目录离线」，目录在线但照片缺失时显示「原图文件缺失」。删除源文件无需弹窗。目录恢复后重新读取照片，挂载位置变动时可以重新定位目录，保留已有照片 ID 和画册引用。

图库保存索引、元数据和可重新生成的缩略图。仅图库资料的备份保留来源关系，恢复后的活动目录需要重新定位。选择「包含全部原片」时，ZIP 同时保存来源原片，恢复时把新补入的照片作为图库副本使用。已解绑来源移动后，当前目录管理入口无法直接迁移它的引用。

## 验收依据

- 用独立图库和混合比例摄影样本核对绑定、确认前零写入照片、首次同步和批量发现。
- 分别忽略新文件夹和已有相簿里的照片，验证重启、目录重连及后来新增照片时的范围。删除相簿后核对来源文件仍在，已有画册保留引用。
- 原生桌面检查正常和窄窗口的弹窗、键盘焦点和离线占位。硬盘离线时打开相簿和混合来源的画册，接回后核对原位置恢复。将物理硬盘实测与模拟目录离线分开记录。
- 检查原件字节、图库备份及恢复结果，确认原始照片没有进入图库管理原件目录。
- 确认多个相簿的同步后立即可导航和编辑画册；原生检查卡片状态、实际进度、单个失败及重试。核对同一来源串行执行和每个相簿独立提交。
- 同步中退出并重新打开时，已确认任务自动恢复，已提交记录不重复，关闭期间加入的未确认文件仍需确认。
