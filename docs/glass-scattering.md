# 非具象深色玻璃散射修订

2026-10-30，用户明确纠正：雨天玻璃是对自然、不规则光影与通透变化的比喻，不要实际水滴，不要背景贴图。本轮去除具象水滴，保留真实系统毛玻璃和B控件，只调整外壳材质表达。

场景为摄影浏览与画册创作。照片与纸张优先；背景只有无可命名形状、连续、低对比的烟黑密度变化。用代码描述低频不规则透射遮罩，改变同一中性烟黑层的局部密度，使系统壁纸仍参与材质；不绘制水滴、云朵、圆斑或固定渐变光带，不增加动画、页面底板和文案。

验收检查：具象水滴完全消失；深色保持稳定；宽窄窗口不见色带、重复缝或贴图形象；照片、纸张、文字与控件无污染。功能与代表状态分别核验，原生单窗口截图不证明桌面合成或真实折射。不同桌面背景下的最终通透观感仍须实际窗口判断。
