# 胶囊导航水滴流动动效

2026-10-31，用户要求导航切换时选中按钮呈现水滴流动的动画。本轮保留现有胶囊静态外观、字体、卡片、背景、其他按钮，只增加选中块的空间过渡。

## 方案与边界

选中浅胶囊在深槽内连续滑动，途中适度横向拉长/轻压缩，到位收拢，目标约0.4–0.55秒，不做大幅弹跳或光斑/粒子。选中块作为持久装饰层，默认可见，首帧原位，不opacity0开场，不用离场动画决定业务。快速切换应从当前可见形态接续，不排队、不回跳。

以App已提交space为唯一选中依据，未保存确认尚未获准时不能提前移动；search/settings没有当前nav项时直接卸载/停动画，不保留假选中。按钮仍原生button/aria-current/Tab与Space路径，不因装饰层拦截事件。流动穿过标签时保证浅块上为深字、深槽上为浅字；前景文字本身不缩放。支持prefers-reduced-motion即时定位、窗口缩放重新对齐、清理观察器和动画。

已检索beUI公共catalog的tabs/shared-layout-bg：tabs包含通用panel/滚动/roving语义，hover-bg含淡入/离场；直接替换会扩大当前导航语义和WK可见性风险。因此不引入完整通用控件，使用项目已有Motion依赖做本导航专用的持久装饰层，参考其标签对比裁切原则。[beUI tabs](https://beui.dev/components/motion/tabs)。不新增依赖或库式抽象。

验证包括类型/构建、独立源审（状态提交、对比、取消、减少动画、尺寸）、原生真实切换和尽可能采集实际中间帧。静态终态不能替代动态通过。无关纸张/字体/background卡片hash保持。

## 第二轮：边缘推进与书架对齐（2026-10-31）

用户实际反馈首版像普通滑动，水滴感不足。新方案保持全部静态导航样式，以前后边缘不同的连续推进速度形成伸展，再在600ms内柔和合拢，轻微纵向压缩由实际伸展驱动。快速反向从当前边缘接续；已提交space、dirty拦截、减少动态效果与卸载清理约束保持。

同时修正画册书架与相簿页面的布局断层：标题/数量同一基线，主操作保持同一高度与纵向位置，内容起点和左右基线统一；取消书架独立限宽和操作负边距，以既有图标按钮收拢元数据操作，不更改书封、纸张、相簿、字体或背景。成功工作区导航后共享main归零，确认未保存修改前保持原滚动位置。验收对照收藏/作品/搜索→画册、宽窄窗及书架操作和编辑器隔离。
