# 相簿连续虚拟滚动

## 本轮方案（2026-11-04）

用户场景：在同一本相簿持续向上、向下观看全部照片，不再在每60张处换页。作品分组、总览与展览、大图前后顺序，以及拼图和模拟排版返回位置应保持一致。

审美意图：保持现有中性深色连续背景、照片原比例与完整构图、4px展览细缝和单图观看尺度；移除分页造成的观看断点。新增照片依靠提前准备和轻微图片明度交接自然出现，不对照片墙做整体位移、隐藏或入场动画，不增加常驻说明。

实现方案：全量照片只生成一次稳定坐标和总高度；展览沿用当前切片树评分和分块，通过Web Worker计算，避免大相簿首次几何搜索阻塞主线程。单一虚拟画布统一承载作品分组标题、展览块及总览行，仅挂载视口和上下预备区。滚动沿用系统原生行为，不监听或阻止wheel；每帧最多检查一次可见块范围，仅范围改变才更新React。焦点项保留挂载，Tab跨虚拟边界显式定位相邻照片；选择仍为全量稳定ID集合，菜单范围与原件规则保持。

验收依据：类型检查；几何、虚拟窗口、全量顺序回归；真实混合摄影内容的宽/窄窗口首段、中段、尾部；原生上下连续滚动、选择/清选、键盘菜单、大图前后、拼图/模拟排版返回。功能检查与设计/动态验收分别记录；纯Node耗时只作为诊断，不作为release性能承诺。

设计落实：保留中性连续背景、既有照片观看尺度、完整构图和细缝；去掉分页控制及换页断点，预备区域使新照片提前读取，不引入整墙位移或依赖透明入场。代码和几何检查不能证明真实桌面已达到“高级”及“设计感和质感”，原生动态与视觉结果由主代理另行补充。

## 2026-11-05 万张相簿优化与 release 实测
