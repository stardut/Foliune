# 拍摄策划 v2：按现场画面组织

本轮基于已确认的人像策划调研，延续当前中性深色、连续系统玻璃背景与既有控件，不新增全局视觉体系。

## 场景与当前证据

摄影师在准备时组织几组可连续执行的拍法，现场与模特直接看“这一组接着拍什么、参考哪张、借鉴什么”。已检查 `.build/verification/planning/final-reading-wide.png` 与 `editor-narrow.png`：旧版首段以文字栏目为主、参考图统一置底，无法表达参考与目标画面的关系；窄窗编辑的大段全字段表进一步拉长阅读。

## 视觉与交互方案

全案概览只承载标题、创作意图、日期地点与团队交付；整体视觉承载少量共同方向及有逐图意图的全案参考。主体为有序 Part：组标题、共同拍法和可选场景/造型/光线/情绪/时间只写一次，其下逐个目标画面呈现主样图与补充参考、参考意图及紧邻现场提示。执行准备放在末尾。

照片保持完整比例。宽窗画面采用主图占较大列、现场提示占窄列的编排，补充参考在同一画面内继续展示；窄窗自然转为图、意图、拍法的纵向顺序。以章节间距、序号、标题和对齐表达层级，避免每一层叠加面板。照片不覆盖常驻工具；编辑时在图下给出顺序与移除入口。

编辑默认提供轻量组名/画面名、图片、简短共同拍法/现场提示；细项通过“拍摄安排”“画面细节”“全案信息”展开，已有细项默认展开，入口一直可见。Part、画面及参考均提供前后排序按钮，照片额外支持 Alt+方向键；每组参考不重复，同照片可以跨画面绑定不同意图，首张为主样图。含内容的 Part/画面删除须确认，空草稿可直接删除。

## 状态与边界

仅策划标题必填，空 Part/画面名以 Part 01/画面 01 阅读。最多20 Part、共100画面、共120参考；结构使用稳定唯一ID。保留保存失败输入、缺失图反馈、加载/空态、未保存导航及关窗保护，保存/导出期间禁用编辑和离开。取消选图不修改内容；选图沿用图库选择器，移除引用不删除图库照片。

长图使用同一有序内容契约，概览与整体视觉后逐 Part、逐画面输出图片及紧邻意图与拍法，最后执行准备。逐张原图解码与绘制，缺图拒绝，1080px宽及既有限额保持，超限明确拒绝。

## 验收依据

功能检查覆盖草稿保存、层级及参考排序、跨画面独立意图、删除确认、错误保留、未保存保护与取消导出。导出内容测试核对层级顺序、完整字段、主图与补充意图邻接及显式换行。类型检查与生产构建只证明结构可构建。

设计验收由主代理在独立图库的 release 原生应用执行，使用真实混合比例照片核对宽/窄窗首中尾、照片完整构图、现场提示相邻、菜单与焦点、动态可见与关闭无残留；长图实际输出核对手机阅读密度。当前旧截图仅作问题证据，不能证明 v2 视觉已通过。高级感与设计质感以作品主次、完整照片、清晰现场关系及真实应用观感判断，不以自评分替代。


## 2026-11-03 实施与验收

### 已实现

- 全案概览、整体视觉、有序Part及目标画面、执行准备；按需展开细项，已有内容默认可发现。全案、Part、画面均可带逐图参考意图，画面首张为主样图，其余为补充，同一照片跨画面保留独立说明。
