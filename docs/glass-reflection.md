# 深色玻璃反光可感知修订

2026-10-30，用户再次明确反馈上一版光泽看不出来，没有深色毛玻璃质感。上一轮源码和可读性通过不代表材质感获认可，本轮以用户反馈为准返修。

目标保留深黑区域与B控制层，显著提高背景亮面、漫反射肩部和暗部之间的可感知关系。不能只把“存在渐变”作为交付依据；原生同首页须明显读出宽缓表面变化，且亮面不能整窗发灰，照片不得受覆盖/调色。允许进一步重设反光尺寸、位置和幅度，避免孤立彩色光斑、硬分割线和照片上叠光。系统玻璃仍为原生HUD，CSS反光与实际桌面合成分开说明。

本轮优先限定外壳背景样式，不改照片、布局、B按钮/导航、业务或纸张。使用原生前后对照与宽窄代表状态检查，保留真实截图；若仍只能勉强辨认，不称质感成立。构建/源审与视觉分别记录，用户最终审美认可单独记录。

## 实施与验证

仅改变`index.css`的`.app-shell background-image`。左上窗外光源`(-24%,-22%)`、120%×150%椭圆：22%→20%亮肩→11%→3.5%→透明（82%）；右下窗外弱回光5.5%→2.5%→透明；下半部暗部逐渐加深至24%。原深黑基底、B控制层、承托、native与布局均未动，无新伪层、照片叠光、模糊、滤镜或动画。

前端构建（含TypeScript）及macOS release `.app`构建通过，资源`index-DjqznB5U.css` / `index-DhdHYIvr.js`。通过Avenil加载独立验收实例`app.foliune.dark-review`，最终PID53960，保持首页。55项冻结指纹一致，唯一本轮差异为上述背景规则。

原生实际检查宽首页、弹窗打开/取消、系统Top Left窄首页及还原，照片与按钮未见遮挡或叠色。证据`.build/verification/glass-reflection/{before-native,after-native,final-native,narrow,dialog}.png`；宽图2640×1760、窄图1842×1242。

独立源审及五图对照认为“反射变化直接可感知”这一项通过：左上至左中宽亮面与宽肩部可直接辨认，右侧/下部保有黑位，窄窗同样可辨；不再依赖像素采样寻找差异。未发现确认需修的安全或可读性问题。但独立审查也指出它仍可能被读成有表面光照的深色底；用户期待的深色毛玻璃质感尚未得到确认，不能把反射明显等同材质最终达标。

本轮无业务代码或图库写入，不重复全链、照片墙中末段、纸张导出、外部AI、完整动效或其他平台测试；纸张/native未动另有源码隔离证据。本轮截图不证明壁纸透光或桌面合成，系统材质与CSS反射分别记录。后续以用户实看反馈决定，不将用户否定的上一轮弱光作为审美通过基线。
