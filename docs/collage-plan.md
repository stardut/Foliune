# 相簿拼图方案

从相簿选择两张以上照片进入独立工作台，不增加顶部导航。工作台以大幅成片预览为主体，右侧只保留布局、画幅、间距、留白、背景及当前照片的必要控件；底部选片条承担排序、补片和移除。沿用现有烟黑材质、浅色主按钮与细内缘，照片像素和输出纸面独立于应用外壳。

自适应按顺序分行并完整保留比例，长图逐张完整纵向排列；网格允许等比裁切，双击当前照片进入拖动、缩放调整，可恢复完整显示。画幅提供自适应、方形、横向及竖向。选片支持拖动插入、两图交换与 Alt+方向键排序。布局及照片调整都进入撤销历史，快捷键为 Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z。

返回相簿保留原滚动位置和选择。工作台会标记未保存状态，返回和顶部导航均要求明确放弃；保存对话框提供名称、同图库相簿搜索、默认来源相簿、新建相簿和实际输出尺寸。取消与失败保留编辑。后端读取管理原件生成 PNG 新图片，经现有候选取舍原子确认；满额时进入统一取舍。成功回原相簿，仅在右上角短暂提示「保存成功」。

验收分开记录：纯函数验证比例、顺序、覆盖、无重叠、极端尺寸与历史；类型检查和构建验证接口。原生应用用真实横竖混合照片检查宽窄窗口、三类布局、裁切拖缩、键盘和拖排、保存/取消/容量取舍、导航保护与返回恢复，截图由独立验收者留存；未经真实运行不声称设计通过。
