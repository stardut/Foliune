# 模特浏览、详情与编辑（2026-11-03）

首页三列卡片方案已被用户否定，后续首页以[横向档案行](model-overview-rows.md)为准；本文保留浏览／详情／编辑分层与当时实现验收记录，不表示用户认可旧首页视觉。

## 场景与方案

进入模特工作区先比较人物资料和样片，选定档案后查看完整样片与资料，只有点击编辑才进入可修改状态。原实现为单张封面加简短说明，点击直接进入表单；本轮限定浏览与编辑的分层，不修改档案字段、存储和照片原件。

首页每份档案展示最多三张样片，封面优先并避免重复，保持完整构图；姓名为首要文字，性别／城市、少量风格与样片数提供比较依据。空值不堆占位字段，保留搜索与新建。沿用中性深色、已有控件及照片优先的层级，通过组合照片和排版提升档案辨识度，不新增装饰面板。

点击卡片进入只读详情：返回与姓名同一行，右侧为编辑入口；全部样片按业务顺序显示，点击使用已有大图查看。资料以只读文字组织，隐藏未填字段，不显示历史身体资料，不出现导入、移除、设封面等编辑操作。无样片仍可查看资料并进入编辑。

从详情编辑，保存后回到更新后的详情；返回或放弃回详情，未保存保护沿用。新建保存进入详情，新建取消回列表；删除回列表。保留当前档案标签目录、历史字段透传及照片关联安全，不改IPC或数据库。

## 验收依据

功能检查列表→详情→编辑、保存／放弃／新建／删除目标及脏保护，只读详情不暴露修改操作，样片数量、顺序及大图开关；搜索、无样片、缺省资料和长姓名可用。类型、生产构建及针对状态流转的有意义检查与原生验收分别记录。

原生使用独立验收图库中的真实混合比例摄影副本，在宽窗与窄窗检查列表组合、详情首段／末尾、完整构图、文字层级和操作可达性；保留前后截图，独立审查代码及原生证据，不将自动检查视作视觉验收。
