# 背景明度修订

2026-10-30，用户实看反馈背景材质太轻、太灰。本轮只校正连续背景的深度，沿用已确认能透出桌面壁纸的系统毛玻璃，不改变布局、照片、画册纸张与业务。

现有外壳以 `rgba(18,20,23,.40)` 覆盖系统材质，大面积背景仍偏中灰。将唯一基底改为中性烟黑 `rgba(12,14,17,.64)`，降低本身亮度并适度增加遮光，仍保留36%底层系统材质参与。这里的36%是CSS合成权重，不等于实测壁纸透光率。控件、文字和照片保持原有规则，先在真实原生窗口检查整体与对比，再判断是否需要连带调整。

验收：前端构建与原生release打包；同一独立65图测试实例检查首页、照片墙和浮层可读性，核实单一背景与透明宿主未改。无业务/算法变化，不重复无关Rust测试。单窗截图用于明度和控件对照，不能代替实际桌面壁纸合成判断。

## 实施与结果

仅修改 `theme.css` 的 `--surface` 一行，未增加底板或修改布局。独立源码审查确认透明根节点与macOS BehindWindow配置不变；该变量还用于既有欣赏/选片背景及候选缩略图承托，照片无新增滤镜或透明度，纸张有局部变量与白色背景覆盖，独立导出不引用此变量。

`pnpm build`（含TypeScript检查）及macOS release `.app`构建通过，最终资源 `index-D3bIvRA1.css` / `index-CRa6xlfq.js`。Avenil服务“Foliune 深色设计验收”复用独立实例 `app.foliune.dark-review`，本轮PID2372，最终回到首页。

原生检查宽窗首页、新建相簿弹窗打开/取消、照片墙首段、窄窗首页（系统Top Left）与恢复尺寸。对照截图均2640×1760，窄窗1842×1242像素。`.build/verification/background-depth/` 中保存before/after/dialog/wall/narrow证据；同位置背景采样从RGB(48,49,51)降为(33,34,36)，用于说明这组截图内明度下降，不推定所有壁纸环境。主代理实看背景更深、连续，文字、按钮、空封面及浮层边界可辨。

本轮针对用户反馈以更沉的中性基底提升厚度和照片衬托，最终审美与新遮光强度下的壁纸透光仍待用户本机实看；此前透光确认不直接等同本轮强度验收。未改业务、图片与纸张样式，未重复导出、全链路、动效、其他平台及正式分发测试；本轮未重验照片墙中末段，沿用此前结构与功能证据。
