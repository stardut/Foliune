# 展览拼贴布局

本文说明图库“展览”视图的当前实现。2026-10-29 至 2026-10-30 的切片树拼贴已替代早期固定三张、面积权重与底线对齐方案；旧方案及其截图不再代表当前布局。相簿入口和头部交互以当前界面为准，画册排版独立于此布局。

## 实现与职责

- [`exhibition-layout.ts`](../apps/desktop/src/features/exhibition-layout.ts) 是独立几何计算模块，输入照片尺寸、画布可用宽度和窗口高度，输出连续拼贴块及照片坐标。
- [`PhotoCanvas.tsx`](../apps/desktop/src/features/PhotoCanvas.tsx) 测量画布、缓存计算结果并按输入顺序渲染照片，负责选择、详情和大图入口。
- [`PhotoReview.tsx`](../apps/desktop/src/features/PhotoReview.tsx) 提供图库的完整比例大图挑选，复用图库临时选择；[`library-photo-order.ts`](../apps/desktop/src/features/library-photo-order.ts) 共享作品页分段与连续预览顺序，不参与拼贴几何。
- [`library.css`](../apps/desktop/src/features/library.css) 定义展览满宽布局、细缝和上下文浮层。规则限定于图库工作区的展览视图，总览和画册纸张使用各自布局。

## 原比例与连续覆盖

每个拼贴块由横向或纵向二分的切片树组成。叶节点使用照片宽高比；子树包含缝隙后的尺寸满足 `width = a × height + b`，横向和纵向拼接分别合并这条关系，再按整块宽度求高度与坐标。块内照片连续覆盖矩形，只留统一细缝，不通过裁切、拉伸或留洞凑版式。

块内缝由 `EXHIBITION_GAP = 4` 参与几何计算，块间 CSS 间距也为 4px。照片容器尺寸依原比例计算，图片使用 `object-fit: contain`，保留完整构图。选择框和图注叠加在照片内部，不扩大几何区域。

算法只组合连续的照片区间，不排列或调换照片。窗口变化可改变二分方向和块边界，输入业务顺序、DOM 顺序及每张照片恰好出现一次保持不变；保序不要求所有照片排列成等高横行。

## 分块与评分

每块候选包含连续 1–6 张照片，枚举其横向、纵向切片树，并缓存各区间候选。六张区间最多有 1344 棵树，不枚举照片顺序。动态规划从序列尾部向前比较“当前块评分 + 剩余序列评分”，选择整段输入的分块，因此少量照片与不足六张的尾数也是完整输入。

评分同时考虑照片面积、过短边、过高照片、占宽过大的照片及块高，并偏好大图跨越相邻堆叠图的组合，减少连续等高行。评分是软偏好，不保证固定主图、固定面积比例或每块同样高；窗口高度参与评分，几何仍由原始比例决定。

空输入或非正、非有限的画布宽度返回空布局；无效照片尺寸在计算中按方形比例处理。候选产生非正或非有限尺寸时会被拒绝；有效输入若无法选出布局会明确抛错。

原比例、满宽和完整构图也有数学边界：单张竖图铺满宽度时必然很高，极端宽图可能很矮；少量照片或极端比例不一定同时满足评分偏好的最短边和高度。实现保留比例与覆盖，不把软评分当作所有输入都能达到的视觉下限。

## 交互与计算成本

静止时照片为主体，不再叠加编号、文件名和渐变工具带；悬停或键盘焦点进入时显示轻量更多入口，选择反馈独立保留。常规操作使用系统原生菜单，支持右键、更多按钮、Shift+F10/菜单键；单击选择、双击详情。未选照片的菜单只针对该照片，已选照片的批量操作使用完整当前结果的已选集合，菜单标明数量。图标保留可识别名称，键盘焦点有内框。照片使用 `initial={false}` 保持默认可见；选择数归零时直接卸载选择栏，交互正确性不依赖退场动画完成。

几何结果由 `useMemo` 缓存，依赖照片尺寸签名、画布宽度、窗口高度和视图类型。选择、悬停以及父组件创建内容相同的新分页数组不会触发几何搜索。`ResizeObserver` 和窗口 resize 更新尺寸，卸载时回收监听。

图库在分段前统一分页，每页最多 60 张；作品分段可分别调用画布。选择状态与页码分离，相簿的“欣赏”使用过滤后的完整照片序列。照片菜单的“放大挑选”按照片墙当前完整呈现序列连续浏览；作品先复用每页既有分段再逐页连接，保持页内、页间顺序，不另行全量重排。大图中选择与墙面同步，返回保留原页与临时选择。分页、候选树缓存和 memo 限制当前计算与渲染范围，不构成大图库性能承诺。

## 已执行验证与边界

2026-10-29 至 2026-10-30 的独立审查覆盖上述三个源文件及拼接方程、尺寸拒绝、1–6 张分块、保序和监听回收。独立几何检查使用真实素材尺寸，在 896/1296px 可用宽度下验证 1/2/4/5/7/11/36 张共 14 组输出，叶节点比例误差不超过 `1e-7`；实现者另执行了 288 组几何断言，两者是不同来源的证据。

真实 macOS Tauri 窗口使用独立恢复图库，经系统文件选择器导入 36 张真实摄影；在 1320×880 与 920×880 窗口的首屏、中段、尾部检查拼贴，并实际缩放、滚动、选择、键盘进入详情、关闭详情、进入欣赏及切换总览。该样本未见内部空洞、拉伸或裁切，照片有大小和横竖变化，细缝约 4px，选择与浮层未改变布局。

少量照片、尾数及合成极端比例只有几何检查，未逐种排列做原生操作。Node 单次计算耗时和本机 release 导入观察只属于当时机器与样本，不能推导所有图库的性能；Windows、真实跨页操作及大图库压力仍未在本轮验收。

完整本地记录为 `.build/verification/mosaic/review-verification.md`，截图及数据证据位于同目录。它们是忽略的验收产物，可能不随检出提供，也不是运行或理解实现的依赖。通用原生验收方法和其他主流程覆盖见[桌面验收](desktop-verification.md)；实现细节以本文链接的当前代码为准。
