# 模特档案与社交排版

> 最新修订：社交排版仅临时预览，不保存或提供草稿；固定头像昵称并按平台适配文字。当前约定见 [仅模拟预览](social-preview-only.md)，下文保存及草稿描述为历史方案。

## 2026-11-02 已确认范围

用户需要维护人像模特基本信息和样片，并在发布前模拟社交软件排版。首版确认：

- 模特：姓名／昵称、联系方式、常驻城市、风格标签、备注、性别、生日、身高、胸围、腰围、臀围、封面及多张样片。
- 排版：微信朋友圈多图动态、小红书图文笔记、Instagram 多图帖子和个人主页网格。
- 排版草稿本地持久保存，可重新打开预览；本轮不包含导出与平台发布。

## 场景与视觉方案

「模特」保留一级入口。「排版」按用户最新指示作为相簿选片后的操作，不占顶部导航；复用已有胶囊导航、按钮、输入框、弹窗和连续系统深色背景，不改既有图库、画册纸张和窗口材质。

### 2026-11-02 入口调整

场景：用户先在收藏或作品相簿中选好照片，再查看社交平台的发布效果。选择栏提供「模拟排版」，按相簿当前业务顺序带入已选照片，直接打开草稿编辑器；不自动写入草稿。退出后回到原相簿，保留选择、页码和浏览方式，未保存内容沿用离开确认。图库 Escape 清选不作用于排版编辑。

已保存草稿通过相簿现有更多菜单中的「排版草稿」访问，保持当前图库原有草稿可重开，不新增相簿归属字段或迁移数据。草稿列表返回相簿，新建走相簿选片入口。顶栏仅保留收藏、作品、画册、模特，原有平台预览、保存及数据安全规则保持。

验收重点为选片范围与顺序、进入及返回原相簿、离开／原生关闭保护、旧草稿重开、宽窄窗选择栏与导航层级。以照片与当前任务为中心，减少一级入口占用，不增加照片上的常驻工具。

模特首页以样片封面与姓名组织档案，避免表格化后台；详情以样片为主体，资料按基本资料、身体资料分组。无样片有明确添加入口。编辑显式保存，离开未保存修改需确认；删除档案确认后只删除资料及样片关联。

排版采用工具与预览并列结构，窄窗改上下结构。工具区包含草稿名称、平台、身份展示名、标题／正文、选片与排序；预览内部使用对应平台的阅读结构，外部继续沿用 Foliune 材质。朋友圈显示多图组合，小红书与 Instagram 帖子支持翻页，Instagram 主页以三列网格检查作品相邻关系。平台切换保留选片与文字，不静默丢弃超出单条展示数量的照片；必要时提示并阻止保存不合法草稿。

照片浏览保持原比例；平台的封面、缩略网格和帖子裁切属于预览显示，不改原件。选片复用稳定照片 ID。样片可从图库选择或通过已有导入接口添加到作品库。草稿不复制照片文件。

## 数据与工程边界

档案、草稿及有序照片引用使用当前图库 SQLite，独立模块及 IPC，不写 localStorage。引用校验、重复项、长度、日期、身体数值和平台枚举由后端校验；事务保存，不允许半份档案或半份草稿。封面必须来自当前样片。切库后重新读取并清除旧编辑上下文。

新表随数据库快照备份，恢复需校验档案、草稿和照片引用；恢复旧备份时允许通过正常初始化补建空表。删除不删除原件、不改变相簿、画册或其他档案。平台画面是发布前布局模拟，不承诺与各版本客户端像素一致。

## 验收

功能：建立／编辑／重开／删除档案和草稿、重复及无效引用、样片顺序与封面、字段校验、四种预览、平台切换、图片顺序、未保存离开、切库隔离与备份恢复。

设计：真实混合比例摄影，宽窄窗、空态、缺图、长中文、键盘焦点、弹窗关闭与保存反馈；照片优先、界面语言一致、无平台样式污染画册和全局。原生动态交互与静态／结构检查分别记录，未验证项明确标注。

实现、独立代码及截图审查已完成；macOS release 原生操作、返修与未测边界见 [验收记录](models-social-verification.md)。
