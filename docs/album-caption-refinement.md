# 相簿卡片信息区精修

## 范围与意图

2026-11-03，用户认为相簿卡片底部标题信息区过灰，已确认将底色压暗、收紧高度并弱化边缘。场景是收藏与作品首页的相簿浏览：封面保持视觉主体，名称和数量仍在同一卡片底部，以紧凑、安静的中性深色承托作品。

沿用现有系统无衬线、名称/数量层级、上图下字结构、12px 圆角与封面比例，不新增渐变、不提取封面色。窗口基底、全局面板及共用封面材质不调整，避免影响导航、其他页面和画册。

## 实施值

| 项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 信息区底色 | `--panel-solid: #2a2c30` | 相簿专用 `--album-caption: #141619` |
| 信息区高度 | 76px | 64px，减少约 15.8% |
| 信息区内边距 | 14px 18px | 10px 18px，保留两行名称空间 |
| 默认外边缘 | `--cover-edge: #ffffff12` | 复用 `--edge-light: #ffffff0a` |
| 悬停底色 | 与默认相同 | `--album-caption-hover: #191b1e`，轻微提亮 |
| 悬停外边缘 | `--control-edge: #e5e9f04d` | `--cover-edge: #ffffff12` |
| 悬停阴影 | `0 5px 18px #00000028` | 保持默认 `--cover-shadow`，不再加重 |
| 悬停名称 | `#fff` | 保持默认 `--ink`，通过卡片表面反馈悬停 |

相簿专用色值集中在 `theme.css`，仅由 `library.css` 的 `.album-open` 使用；不修改同时供模特卡片使用的封面变量。默认与悬停仍保留 150ms 表面过渡，沿用现有减少动态效果规则；禁用卡片不应用悬停/按下反馈。键盘焦点及名称截断规则保持现有实现。

## 验收依据与状态

- 静态边界：只调整相簿入口卡片外观，不改照片、相簿数据、列数、封面构图及交互流程。
- 功能检查：`pnpm typecheck`、`pnpm build` 均通过。Vite 仍提示 API 模块混合静态/动态导入和产物块大于 500kB，均与本轮 CSS 调整无关；未构建桌面程序。
- 原生设计检查：通过 Avenil 重启既有「Foliune 拼图验收」独立实例，macOS release 0.1.0，使用原有海景、天空、植物、夜景与拼图封面。宽窗截图 2640×1760（1320×880 逻辑尺寸）、窄窗 1852×1252（926×626），检查首页首段、后段与末尾：信息底色更贴近窗口，名称/数量可读，卡片边缘减弱，没有遮挡或溢出。鼠标打开 Square 相簿并返回、Tab 定位首张卡片和回车打开 65 图相簿均通过。未写照片或相簿数据；最终恢复宽窗首页。
- 截图与构建日志：`.build/verification/album-caption-refinement/` 下 `before.png`、`after-wide.png`、`after-narrow.png`、`after-narrow-end.png`、`keyboard-focus.png`、`build.log`。前后截图导航多出「策划」来自本轮打包前仓库已有实现，本轮未修改导航。
- 限制：两行长名称仅核对 CSS 可用高度（44px 可容纳两行 21.6px），尚无原生长名称样本；悬停/按下完整动态、禁用、空/缺图、系统减少动态、不同壁纸与 Windows 未实测。悬停与禁用规则仅源审。
- 本轮以减轻底板、保留中性承托和文字层级落实照片优先及质感要求。已测静态与基础交互范围符合方案，完整动态及最终审美认可不由截图推定。
