## 取色职责与状态

检索项目后未发现现有取色工具；策划 PNG 仅提供独立 canvas 绘制和 anonymous 图片加载的先例。新增书架专用小模块，从已有缩略图离屏 32px 小样本的下部取得单一低饱和色，不修改照片像素、不新增持久化或设置。书名颜色以 WCAG 相对亮度公式计算，选择至少 4.5:1 的明暗文字。

取色独立于复用的 PhotoImage 显示链路，匿名 CORS 加载只用于 canvas。采样失败（包括 CORS 或画布污染）明确显示「封面配色不可用」并保留中性底；不重试其它来源、不以取色结果控制照片可见。照片读取错误继续由 PhotoImage 呈现。加载期间采用中性底，完成后直接应用单色；无照片保留素色标题封面和已有不可用反馈。

当前版本第一有效照片规则、单击打开、右键和键盘菜单保留。删除确认文案改为画册及其内容，不再提版本。长标题在固定双行区域截断，完整书名仍通过按钮可访问名称和 title 提供。
