# B方案背景深度与整面光泽

2026-10-30，用户反馈B原生版仍不够深，160px顶部入光之外的大面积背景像固定纯色，要求类似参考应用的连续光泽变化。本轮保留B导航/按钮/承托与真实系统玻璃，只校正基底深度和整面明暗，不改布局、照片、纸张或业务。

计划将唯一中性基底从`rgba(10,12,16,.84)`加深为`rgba(5,7,10,.90)`；旧160px短顶光改为全窗尺度的宽大漫反射、极弱远端反射及柔和纵向暗部过渡。光源以相对窗口比例定位，使用中性低强度、无硬边渐变，形成可辨但不喧宾夺主的明暗；避免彩色光斑、斜向分割线、噪声、动画、照片上叠层和全窗CSS模糊。

允许整面连续明暗，是用户本轮明确要求的背景变化，仍遵守不逐区换底、不靠多色块切割的规范。native HUD、Dark/Active和透明根节点保留，加深会收敛壁纸参与，不能声称CSS光泽等于系统透光。

验收：前端/原生构建；同一独立测试首页前后图、宽窄、设置/弹窗与画册代表状态，重点看背景不只上端变化、整体比旧版更深、文字和照片保持清楚。独立审查代码/原生截图。无业务和算法变化，不重复无关全量Rust测试。单窗图不代替壁纸实际合成或所有背景矩阵验证。

## 实施与结果

仅修改`theme.css`唯一基底和`index.css`的`.app-shell`背景图像两处，B控件/承托及native HUD/透明设置未改。整面渐变为左上115%×105%椭圆宽漫反射（8%→2.5%→透明）、右下90%×85%椭圆极弱反射（2.5%→透明）和从上到下0→3%→14%的暗部，均为背景绘制，不覆盖照片或纸张。

前端构建（含TypeScript）和macOS release `.app`打包通过，资源`index-WcZb7OzT.css` / `index-iaFEdQnW.js`。用户解锁后fresh核对首页无未保存内容，经Avenil重启独立服务“Foliune 深色设计验收”，最终PID43570保持新版首页。

原生检查宽窄首页、相簿新建弹窗打开/取消、已有3页画册白纸/照片/字幕，再恢复首页。宽图2640×1760、窄图1842×1242，证据`.build/verification/background-sheen/{before-native,final-native,narrow,dialog,book}.png`。同图内空白区域样本从旧上左RGB(35,36,40)/中下(29,30,34)变为新上左(29,30,34)/中下(16,17,21)/右下(19,20,24)，证明这一组捕获中整体更深且远离顶部仍有变化，不作为桌面合成或所有壁纸下固定亮度证据。详细采样在`background-samples.json`。

独立源码与上述五图审查未发现确认需修项：全窗宽缓明暗、深色读性、B控制层、照片与纸张隔离在已供范围通过。冻结55项源码指纹一致，仅两CSS改变；未改业务，无新增数据构造或写入。此轮以更深基底与连续光泽落实质感方向，不等同用户最终审美确认。

未重测设置、照片墙中末段、全链动态、外部AI、HTML导出、Windows和正式分发；没有改系统壁纸，不将单窗截图或CSS光照等同真实透光强弱。本轮变化是可控背景光泽，系统玻璃底层保留，加深对壁纸参与的权衡仍以本机实看为准。
