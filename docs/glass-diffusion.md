# 去除固定渐变走势的玻璃密度细化

2026-10-30，用户认可前版改善，但仍像深色渐变，要求更自然的玻璃通透感且不得整体提亮。本轮不再单纯放大明暗幅度，改进同一烟黑透明层内部的空间分布：削弱跨窗单一宽光带，采用多个尺度交织的连续密度变化，保持现有深色基底、照片主次与真实系统HUD。

只调整背景密度场，不加入具象水滴、装饰贴图、白色光斑、动画或额外模糊。默认保留base与alpha映射；如原生同窗测量显示明度上升，校正密度分布后复验。平衡自然、不规则和安静，不能把多个云团替代一个大渐变。

验收使用同窗旧/新对照及宽窄首页、弹窗与既有画册，观察固定明暗走势是否削弱、是否出现噪点或图案、文字/照片/纸张是否干净。以多个相同无内容区域采样辅助判断明度，局部取样不代表整窗或桌面透光。静态密度场只调节系统毛玻璃的局部遮光，不模拟真实折射；最终材质认可仍看用户实窗反馈。

## 实施过程

首版只将密度场初层改为约4×5个跨窗起伏、2→3octaves。原生图`rejected-wide.png`虽然削弱了单一渐变走势，但主代理实看底部斑驳偏重、读成云雾，未判通过。下一版保留空间交织，将alpha相对`.708`中值的偏移压至`.60`倍，降低斑块对比；base仍`.64`，无白色提亮、图形或额外层。理论中值并不代表实际均值。

独立源审确认冻结一致、映射变更正确及资源一致，无新增内容污染路径；最终六张图独立审查确认大范围单一走势减弱、较拒收首包明显收敛，内容干净，但宽窗下半部及窄窗空相簿仍有低对比模糊云雾感残留。因此本轮技术/内容隔离通过，自然玻璃设计验收未完全通过；不声称云斑消除或高级感达标。真实壁纸通透、浅深复杂桌面矩阵、物理折射、用户最终高级感未据此判通过；未重测完整动效、图库中末段、导出、其他平台、性能或正式分发。
