# 工作区切换与画册响应

## 本轮场景与方案（2026-11-04）

用户反馈工作区切换缺少动画且卡顿，进入画册尤为明显。本轮仅优化工作区交接和书架封面准备，不改变画册视觉设计、照片构图、纸张、编辑或导出行为。

沿用中性深色连续背景与现有悬浮导航，导航和内容采用协调的短促节奏。新页面以约240ms、6px的轻位移进入，基础样式保持可见；离开直接卸载，不等待退场，不叠放两份业务页面。系统减少动态效果时直接呈现。照片和书名保持视觉主角，不增加装饰、加载说明或逐张排队的动画。

画册性能重点核验：进入时是否重复获取书架、封面尺寸初始化是否重复启动排版、字体等待及离开后的旧任务是否继续耗时、候选位置是否重复扫描同一图片。优化应保持最终封面设计一致，以精确输入复用已完成的设计，防止过期数据、失败结果或无限增长的缓存。

## 验收依据

- 可执行回归覆盖重复进入、卸载后取消、尺寸变化与缓存输入失效，保留修复前失败及修复后结果。
- 类型检查、前端生产构建与独立代码审查；仅前端改动无需重复无关Rust业务测试。
- Avenil管理的macOS release隔离实例，真实横竖方摄影书架，收藏／作品／画册／模特／策划快速切换、返回书架、打开画册及关闭，宽窄窗口下无空白、残留或封面跳错。
- 截图说明静态视觉；动画平滑及性能改善仅按实际可获得的运行证据记录，不将构建或脚本耗时推定为原生帧率。

## 诊断基线

真实React组件生命周期测试 `node --test apps/desktop/tests/book-cover-lifecycle.test.mjs` 在修复前3项失败。240px首挂载：字体加载6次、初步排字2次、图片采样2次、封面设计2次；卸载后字体迟到仍继续2次采样/设计；相同输入两次进入共4次采样。此证据定位重复工作，不是原生耗时或帧率。

原生基线为 `app.foliune.book-review` 的macOS release隔离实例、1320×880逻辑窗口、6本真实摄影画册与71张照片。仅浏览工作区，未编辑内容。优化前截图保存在 `.build/verification/workspace-transitions/before-books.png`；全表行及原件SHA基线在同目录 `baseline.json`。

## 实施与验证结果

- 本轮实际改动为 `index.css`、`BookCover.tsx`、`book-cover-design.ts` 及两份封面测试。App与BookWorkspace保持当前实现，工作区继续直接卸载；入场只作用于标题和实际列表叶容器，避免改变主滚动容器、虚拟画布与fixed浮层祖先的几何。
- 统一240ms、6px、opacity .92→1，不使用填充模式和退出等待。书架等IPC列表实际挂载时才入场；减少动态效果时关闭。
- 首次准备以实际尺寸为准，仅邻近视区开始分析；成功结果按完整输入保留最多128项，挂载实例持有自己的排版，避免全局淘汰使已显示封面退化。离开取消在途图片采样与等待中的计算；失败不写成功缓存。候选字号共用一次亮度矩阵，排版公式保持。
- 类型检查、22项封面算法/React生命周期测试、前端生产构建、macOS release隔离app构建、全工作区 `git diff --check` 通过。独立审查发现的缓存淘汰问题已先复现、修复、补测试，并经独立复跑22/22，无剩余P0/P1/P2。
- 128组固定样本、书名、尺寸与人工区域的算法输出前后deepEqual。Node算法计时受本机并行构建影响，不将其作为原生性能改善百分比。

最终原生实例为 `app.foliune.book-review`，由Avenil「Foliune 画册装帧验收」管理，最终资源 `index-CI8sqvFp.js` / `index-CbQ_Epow.css`。本次仅浏览隔离图库6本画册/71张真实混合摄影；1320×880宽窗、925×625窄窗及末尾检查，收藏→作品→模特→策划→画册、画册冷进入、往返重进、打开Cloud Studies→书架可用，无观察到的空白、旧页面残留或无法关闭状态。最终缓存修复包再次构建、重启后补查画册冷进入、往返、宽窄与打开返回。没有执行内容保存或照片写入。

截图、构建日志、调用次数基线与后置输出、原生连续截图及采样时间、全表行/原件检查位于 `.build/verification/workspace-transitions/`。最终 `integrity-final.json`：全表行与71份原件SHA不变、SQLite完整性ok、外键错误0。独立验收者复核宽窗返回、窄窗首末段与编辑器截图，静态范围未发现新回归。

验收期间工作区同期已有中文封面字体更新，最终构建沿用当时的字体源文件；本轮未编辑字体注册或字体资源。初始原生截图与最终截图的中文字体差异不能归因此次性能优化。算法差分是在同一测量函数下比较。

### 证据边界

连续截图首次采样为点击开始后519ms，已晚于240ms内容入场区间，不能证明整段动画逐帧平滑。本轮完成代码与功能核验、真实摄影静态复核；原生短过渡的完整动态设计验收与release切换耗时/帧率量化仍未验证。系统减少动态效果仅源码规则核验，未切换系统偏好实测；超大书架原生、全部键盘/异常路径、Windows未测。以一致、克制的视觉节奏和减少重复准备落实质感，未以构建或静态截图声称完整动态验收通过。

## 一级页面交接修订（2026-11-05）

从顶部导航、搜索快捷键或设置入口切换工作区时，原先按标题、列表各自挂载触发的 6px 入场缺少统一起点；异步列表返回时还会单独再动一次。沿用胶囊导航的空间反馈与大图过渡的短时柔和节奏，一级页的标题、工具、内容统一在现有滚动区做一次短淡入。背景和导航保持原位，内容从可见状态开始，不改变照片尺寸、布局和交互区域。加载、空态与错误照常呈现；数据到达、首启、同一入口重复按下不另起动画。

以实际工作区变更为准。快速切换由最后一次导航接管；有未保存修改时，仅在确认离开后过渡。系统开启减少动态效果时直接呈现。验收时检查原生宽窄窗的正常切换、快速往返、搜索/设置、旧内容卸载、相簿滚动回到页首及未保存提示，分别记录动态与终态证据。

### 本次实现与原生验证

- `App.tsx` 在一级工作区提交后，对现有主滚动区应用 240ms、65% → 100% 的透明度缓出。不移动容器或保留旧页面；快速切换会取消上一次动画。减少动态效果启用时跳过，播放中启用也会停止。本轮移除 `index.css` 原先针对标题、列表和空态的独立入场。
- 类型检查、Vite 生产构建、44 项相关 Node 测试、macOS arm64 release 构建和独立代码审查通过。资源为 `index-CLCUdH1W.js` / `index-_Gut6Ifj.css`。
- Avenil 管理的 `app.foliune.page-navigation-review` 使用 71 张真实摄影副本、5 本收藏相簿、6 本画册、2 份策划，在 1320×880 和 920×620 的原生 WKWebView 检查顶部导航、搜索、设置、往返与快速切换。原生录屏抽帧可见新页面从较淡状态进入、胶囊继续滑动、照片和标题保持位置；两种窗口最终都回到收藏页，无旧页叠层。画册正常读取后显示真实封面。未保存策划的“继续编辑”保留输入，“放弃并离开”进入收藏；临时草稿未保存，测试数据库完整性检查通过。
- 证据目录 `.build/verification/page-navigation/`，以 `desktop-wide.mp4`、`desktop-narrow.mp4`、`collection-frames.jpg`、`desktop-*-final.png`、`books-loaded.png` 和 `dirty-*.txt` 为准。录屏帧间隔不固定，支持观察过渡及终态，不能用于衡量完整帧率或证明每一帧的流畅度。系统减少动态效果和滚动重置路径只做源码复核，未切换 macOS 系统偏好，Windows 未实测。

## 工作区内交接（2026-11-06）

打开相簿、返回相簿列表、切换展览／总览／单张和进出画册阅读时，目标内容用 180ms 从 76% 不透明度淡入。固定导航、背景和相簿视图控件保持位置。照片墙只在排版及目标位置可用时淡入视口内的单元。快速再切会取消上一段，排版失败会丢弃本次过渡。关闭阅读后立即卸载阅读层并还焦，随后编辑区淡入。系统减少动态效果时跳过，运行中开启会取消。一级工作区交接及导航胶囊时长沿用原值。

Avenil 管理的 macOS 15.0.1 arm64 WKWebView release 隔离实例 `app.foliune.interaction-continuity-review` 使用 65 张混合比例摄影相簿、单张方幅相簿和 5 页画册。被动采样包通过实际原生操作记录目标表面的透明度帧，覆盖打开相簿、列表返回、总览、单张以及进出阅读。采样确认从约 0.76 向 1 过渡，并观察到快速切换取消旧动画。最终正常 release 资源为 `index-BjjXXCQj.js` / `index-Uih1lcxY.css`，无采样脚本。在 1320×880 宽窗和约 921×928 窄窗核对第 31／65 张三种视图往返与相簿返回。画册从编辑第 4 页进入 3–4 页，方向键翻到第 5 页，Esc 回到编辑第 4 页并聚焦「阅读」。原生截图和可访问性证据留在验收聊天，采样摘录及数据哈希位于 `.build/verification/workspace-detail-transitions/`。

类型检查、生产前端、macOS release 构建、177 项前端测试与独立审查通过。隔离的 81 份原件哈希与两库各 19 张表的行哈希一致。减少动态效果通过独立组件检查，未改变 macOS 系统偏好实测。Windows 和原生性能基准未测。
