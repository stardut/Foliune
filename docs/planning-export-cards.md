# 策划 PNG 场景卡片方案

本记录为长图卡片阶段的历史证据；用户后续明确要求弱化卡片感，现行导出方案见[连续纸张长图](planning-paper-export.md)。应用内场景卡片保留。

## 场景与范围

2026-11-03：策划长图用于手机查看及现场沟通。本轮只调整独立 PNG 内容模型及绘制，不改变桌面页面、数据类型或保存行为。导出继续使用独立浅纸张，与应用的中性深色系统玻璃外壳隔离。

## 版式与阅读

- 1080px 宽，灰白背景、白色卡片、清晰细边、克制圆角，不使用投影。外边距44px，卡内32px，卡间28px。
- 前部概览卡容纳主题、创作构想、时间地点团队用途与整体视觉。整组准备紧随其后，仅出现一次；妆造、道具、器材用单列标签和值，空项不占行。
- 每场景独立卡片，场景序号、名称与要点置顶，随后固定“参考图 / 拍摄参数 / 镜头清单”三区。无折叠，草稿空区有简短状态。
- 参考图保持原比例完整显示；单图单列；2–3张最多两列，第三张保持半列宽续行，历史第4张及以后按两列续行。逐图意图位于对应列下方，行高按最长列实测。仅场景图片绘制，旧全案和镜头参考意图保留为全文。
- 场景时段置于标题旁，空间不足完整换行；参数按光影、镜头焦段、场地、场景补充、情绪排列，标签和值按实测行数取较高者，单列读取。旧场景造型仍为场景补充，不推断搬迁。
- 镜头为手机单列纯文字，编号、名称、优先级后保留拍法、姿态、构图、光线、情绪和旧参考要点；自由文字清单全文保留。
- 总题64px，场景48px，镜头42px，正文40px/60px行高，标签及意图36px/54px行高。以结构和间距控制密度，不用缩小字体压缩长文。

## 实现与验收依据

内容模型显式表达卡片开始/结束、分区标题和标签字段，渲染器不猜测文字含义。先测量全部图文、字段、卡片边界，再绘制卡片背景和内容；文字宽度扣除卡内边距及标签列，卡片高度包含所有子内容。

保留逐张原图解码与释放、缺图/解码失败拒绝整次、32768px / 4000万像素 / 64MiB限制及画布清理，不静默丢项、裁切或降采样。

结构测试覆盖准备只一次且前置、卡片数量与边界、图文无溢出和卡间无重叠、长文及多镜头归属、0/1/2/3/4张混合比例、旧意图全文与输入不变、失败释放和尺寸字节限制。类型检查及Node测试只证明结构和逻辑；高级感、真实照片观感及手机阅读需要主代理在原生应用导出真实长图检查，未实测前不宣称视觉验收通过。
