# B方案原生落地

2026-10-30，用户明确选择材质对照原型B（熏黑玻璃），要求落实到实际应用并检查原生毛玻璃下效果。原型`apps/desktop/prototypes/material-study/index.html`中的B为视觉依据，原型控件/场景模拟不进入正式产品。

## 方案与边界

沿用现有HUDWindow、Dark/Active、透明根节点与原生BehindWindow路径，不增加浏览器模拟背景或全窗CSS模糊。将B材质职责落实到共享CSS：稳定中性烟黑基底、仅顶部160px内渐隐的弱顶光、细内缘；相簿完整照片下的轻承托；凹入导航槽与精细银色选中表面；主按钮的短阴影、上沿高光和低幅金属明暗。去掉旧135度斜向渐变，维持连续背景。B原型`rgba(10,12,16,.84)`为初始基准，原生效果另验，不能直接承诺浏览器与NS效果像素一致。

优先复用theme变量与现有组件。控制层区分主/次/quiet/disabled/focus，不把所有操作都做成亮金属块。保留既有无color状态过渡约束，避免原生旧状态残留。不得改变导航结构、业务、照片比例、ID、画册纸张及独立导出，不把反光覆盖到照片上，不加入生产原型切换条。

## 验收

前端构建与macOS release包；独立65图实例检查宽窄首页、横竖方及空封面、照片墙/选择/分页、设置及弹窗、已保存画册纸张。独立代码与截图审查；业务表与原件哈希只读核对。工具单窗截图用于层次/明度/读性，不作为壁纸透光证据；新B的壁纸实看与最终审美另记，不外推旧HUD浅候选的确认。

## 已实施与验收记录

正式实现仅修改`theme.css`、`index.css`、`features/library.css`。B烟黑基底为`rgba(10,12,16,.84)`，旧斜光替换为160px垂直弱顶光，外壳仅内侧光影；导航凹槽与四段银色选中面、工具轻表面、主按钮四段金属表面和较弱普通按钮已落实。quiet、disabled、focus及关键状态即时更新约束保留。相簿细边缘用inset阴影表达，保留inset8px、contain和所有几何。原生HUD/透明配置、业务、纸张、独立导出未修改。

`pnpm build`（含TypeScript）与macOS release `.app`打包通过；资源`index-C-LJK8Yf.css` / `index-CE6G1cXb.js`。原生包仍位于`apps/desktop/src-tauri/target/release/bundle/macos/Foliune Dark Review.app`。冻结源码仅三份CSS相较基线变化，五业务表指纹和65原件SHA一致，证据`.build/verification/material-b/source-freeze.json`与`integrity.json`。

独立源码审查未发现确认问题：quiet按下与disabled覆盖有效；导航文字颜色不依赖过渡；纸张局部变量覆盖普通修复控件，纸张内没有primary按钮，新增primary光影不影响纸张；照片及布局未变。此结论仅为代码审查，不代替原生视觉与交互验收。

本轮通过分离外壳/承托/操作表面落实用户选定的质感方向，保留连续背景和作品主次；不以自评分作“高级感已达标”结论。
