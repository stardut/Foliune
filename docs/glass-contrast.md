# 深色玻璃通透变化幅度校正

2026-10-30，用户认为去水滴后的材质变化太弱，要求保持深色并增强自然、不规则的通透变化。本轮沿用现有非具象密度场，不改变形态、布局、控件、照片、画册或原生HUD配置，仅放大烟黑密度映射的有效范围。

上一版同色`.80`底与低幅度alpha叠加，且低频噪声大部分集中在中间值，实际变化被压缩。此次调整以保留平均深度和暗部为约束，让部分区域保留更多壁纸参与，而非整窗提高亮度。避免硬阈值、可识别云朵、圆斑、雨滴、色带、装饰贴图和动画。

验收：与同窗原生旧版对照，变化应更清晰；同时保持深色、连续过渡、文字清楚、照片与纸张干净。覆盖宽窄收藏首页、弹窗取消和已有画册；单窗截图不独立证明桌面合成、物理散射或不同壁纸表现，最终审美仍以用户实看判断。

## 实现与验证

仅修改`theme.css`同色base `.80→.64`，以及现有`glass-transmission.svg`的alpha映射：21点连续S形采样，提高输入中间区的变化幅度；field频率、seed、2octaves、着色与层级均不变，不新增光影图形或绘制层。理论合成遮光约`.761–.970`，输入`.50`约`.895`，不将此数值当实际均值或壁纸透光测量。

前端类型/生产构建、macOS release app构建通过。资源`index-BFb-XbZ-.css` / `index-C9WwEm8Q.js`，Avenil独立实例`app.foliune.dark-review` PID80857保持新版宽窗收藏首页。SVG1427字节，源/dist一致；证据冻结见`.build/verification/glass-contrast/source-freeze.json`。

主代理实操宽窄收藏首页、相簿弹窗打开取消、既有3页画册打开，没有创建相簿或编辑画册。原生证据在`.build/verification/glass-contrast/`：有效前版`before-native.png`，新版`final-wide.png`、`narrow.png`、`dialog.png`、`book.png`。宽图2640×1760，窄图1842×1242。实看深浅起伏比旧版清楚，仍为深色背景，未重新出现具象水滴、硬边或规则光带，照片/白纸/文字清楚。

同窗无控件背景条带`(500,160)-(2200,300)`只读灰度采样：旧均值23.242、P10/P50/P90=22/23/24；新均值28.362、P10/P50/P90=25/29/31。此区域明暗差扩大，平均也上升约5级，不能声称完全未提亮；不代表整窗均值、不同壁纸或真实系统合成的测量。

独立源审确认只有上述两处调整，21点表单调连续，无硬阈值；独立实看五张对照/代表图，确认宽缓深浅比旧版更易辨、下部黑位保留，未达到整窗发灰，未见硬边、规则色带、可命名云朵或圆斑；弹窗焦点与画册内容干净。本轮“增强变化并保持深色连续”的范围通过，不外推用户最终审美认可。未重测图库中末段、完整动效、导出、其他平台、正式分发或性能。真实桌面透光和浅深复杂桌面矩阵未独立验证，最终材质审美仍待用户实看。
