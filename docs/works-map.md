# 离线作品地图

在「作品」里按拍摄地点回看相簿中的照片。 打开后，读取状态使用首屏同一位置和尺寸的灰阶球面，以转动的淡经纬弧和左下角短状态提示等待。开始时转动较为明显，读取持续时逐渐放缓；数据就绪后底图立即展开，经纬弧同时减速淡出。内容就绪后，球面原位保留。底图由球心向外展开，引线随后从实际拍摄点绘向照片。引线接近末端时，照片与地名一起在原位淡入，保持原色原比例。返回随时可用，系统启用减少动态效果时直接交接。宽窗以地图定方位，在周围放少量不同画幅的代表照。沿用应用的中性深色和系统材质，底图、地点与引线比照片轻。照片保留原比例和原色，展签只保留识别地点和数量所需的信息。窄窗把代表照移到底部，为地图留出完整空间。

地图读取作品相簿中仍有效、且有有效坐标或已手选拍摄地区的照片。同一照片在多个相簿中只计一次。定位沿用图库已有的「纬度, 经度」地点值。在照片详情可为无坐标的作品选择并保存省、州或同级行政区，地区以稳定 ID 保存。无坐标且未手选地区的作品仍可从相簿浏览。归属、分组与引线在本机计算。底图使用 Natural Earth 1:5000 万陆地与湖泊，地区归属使用同源 1:1000 万行政区，两份数据均随应用提供。[数据来源与更新方法](../apps/desktop/src/features/works-map/NATURAL-EARTH.md)

在作品相簿中，可为多选照片或整本相簿一次性填写拍摄地区。保存前显示可更新照片数与跳过的有坐标照片数。整本操作覆盖打开地区选择器时相簿内未废弃的可见作品，保存后逐张归入地图上的相应地区。

以省级行政区为最小浏览单元。国内按省、直辖市、自治区等分组，国外按州、省、都道府县等同级行政区分组。经纬度用于本地归属查询，地图、展签和地点组使用地区名称。手选地区只写图库，不改照片原件或 EXIF。同一区域的坐标照片与手选照片合组。有坐标的代表作品使用拍摄位置，纯手选组使用行政区内的代表点。缩放后同一地区仍只有一个组。首屏用正射投影呈现地球，按作品分布确定初始朝向，为周围海岸和相邻大陆留出空间。拖动转动地球。地图来源、缩放、复位和按需显示的地区入口固定在标题右侧，复位回到初始朝向和比例。放大时圆形视野随之扩大，边缘逐渐柔化并淡入背景。放大和缩小时，球缘、点位、引线与展签按同一进度过渡，保持照片和球缘的间距。海岸、省界、点位和高亮使用同一投影和可见范围，展签随圆缘留出间距。只有正面的地点有点位和连线。球面背后、视野外或点位过于密集的作品可通过地区入口转到正面查看。

总览把更多纵向空间留给球面。海陆用两阶中性灰区分，球面左上略亮、右下略暗，经纬线和密集省界留在后层。宽窗最多放六张代表照，在球面两翼留出清楚的间距，保持球缘和照片构图完整；窄窗将代表照放到底边。真实位置用浅亮点芯和淡外圈表示，引线从点芯接出，折角只保留线条。相邻标记在快要重叠时各自收边，留出细缝，并保留各自的真实中心和点击入口。引线避让照片、其他点位和已有引线，空间不够时其余点位仍可点选。点击点位或展签后，组内作品以贴底的照片带显示。照片带直接叠在地图页面上。地名与数量在照片行的前方，照片可横向浏览。鼠标滑过时，照片按离指针的距离向上等比放大，移开后复原。滚动条隐藏，地图继续可操作。点击地图空白处或按 Escape 取消选中。关闭照片预览回到同一地图位置及照片。没有可定位作品时显示空态，缩略图不可用时沿用图库的反馈。

底图用低对比的灰色细线标出省、州和同级行政区的内部边界。选中点位或展签后，位置点、整条引线与对应照片展签同步提亮，地区用略亮的轮廓和淡填充标出。切换或关闭照片组时更新。边界随地图缩放和平移，照片、点位和引线保持在边界图层上方。

验收使用隔离图库中的真实横竖幅照片。分别在宽窗和窄窗检查首屏球体与照片的比例、地理轮廓和省界可辨、转动时点位与展签的可达性、所选轮廓贴合底图，以及大图返回路径。公开发布所需的地图审核按最终底图和呈现方式另行核对。

首轮取样为 17 张公开许可的实拍作品，覆盖北京、天津和天山天池。测试采用来源页面记录的相机位置写入隔离图库，用于核对北京 12 张、天津 2 张和新疆 3 张的地区归属。
