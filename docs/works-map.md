# 离线作品地图

在「作品」里按拍摄地点回看相簿中的照片。 打开后，读取状态使用首屏同一位置和尺寸的灰阶球面，以转动的淡经纬弧和左下角短状态提示等待。开始时转动较为明显，读取持续时逐渐放缓；数据就绪后底图立即展开，经纬弧同时减速淡出。内容就绪后，球面原位保留。底图由球心向外展开，引线随后从实际拍摄点绘向照片。引线接近末端时，照片与地名一起在原位淡入，保持原色原比例。返回随时可用，系统启用减少动态效果时直接交接。宽窗以地图定方位，在周围放少量不同画幅的代表照。沿用应用的中性深色和系统材质，底图、地点与引线比照片轻。照片保留原比例和原色，展签只保留识别地点和数量所需的信息。窄窗把代表照移到底部，为地图留出完整空间。

地图读取作品相簿中仍有效、且有有效坐标或已手选拍摄地区的照片。同一照片在多个相簿中只计一次。在照片详情、整本相簿设置及 CLI 中，国内地区可以选省或地级市，也包括自治州、地区和盟。手选市显示为市，手选省显示为省。清除手选后，恢复按图库已有的「纬度, 经度」识别。无坐标且未手选地区的作品仍可从相簿浏览。计算在本机完成。Natural Earth 提供海陆底图与全球省州数据，CTAmap 提供国内地级区划数据。[数据来源与更新方法](../apps/desktop/src/features/works-map/NATURAL-EARTH.md)

在作品相簿中，可为多选照片或整本相簿一次性设置拍摄地区。默认纳入有有效 GPS 坐标的照片，勾选「跳过有 GPS 坐标的照片」可将它们排除。保存前显示实际更新数量，已在目标手选地区的照片无需再次写入。整本操作覆盖打开地区选择器时相簿内未废弃的可见作品。

国内 GPS 优先识别地级地区，没有唯一地级匹配时按省归属。直辖市作为一组，国外继续按州、省、都道府县等同级行政区分组。自动归属的照片先按省汇总。有作品的省较少且展签排得开时，地图可将多个省展开到市。手选地区始终保留所选层级，展开后的市可以与手选市合组，每张照片只出现一次。

手选地区以稳定 ID 写入图库，保留原始坐标、照片原件和 EXIF。组内有手选地区与 GPS 归属不一致的作品，或组内没有可用的真实拍摄点时，使用地区代表点。其余组使用代表作品的拍摄点。首屏用正射投影呈现地球，按作品分布确定初始朝向，为周围海岸和相邻大陆留出空间。拖动转动地球。地图来源、缩放、复位和按需显示的地区入口固定在标题右侧，复位回到初始朝向和比例。放大时圆形视野随之扩大，边缘逐渐柔化并淡入背景。放大和缩小时，球缘、点位、引线与展签按同一进度过渡，保持照片和球缘的间距。底图和点位使用同一投影和可见范围，展签随圆缘留出间距。视野稳定后才重新判定省市展开，保持拖动中照片组稳定。只有正面的地点有点位和连线。球面背后、视野外或点位过于密集的作品可通过地区入口转到正面查看。

总览把更多纵向空间留给球面。底图只绘制海陆、湖泊和经纬网。海陆用两阶中性灰区分，球面左上略亮、右下略暗。宽窗最多放六张代表照，在球面两翼留出清楚的间距，保持球缘和照片构图完整；窄窗将代表照放到底边。真实位置用浅亮点芯和淡外圈表示，引线从点芯直连展签。相邻标记在快要重叠时各自收边，留出细缝，并保留各自的真实中心和点击入口。引线避让照片、其他点位和已有引线，空间不够时其余点位仍可点选。点击点位或展签后，组内作品以贴底的照片带显示。照片带直接叠在地图页面上。地名与数量在照片行的前方，照片可横向浏览。鼠标滑过时，照片按离指针的距离向上等比放大，移开后复原。滚动条隐藏，地图继续可操作。点击地图空白处或按 Escape 取消选中。关闭照片预览回到同一地图位置及照片。没有可定位作品时显示空态，缩略图不可用时沿用图库的反馈。

选中点位或展签后，位置点、整条引线与对应照片展签同步提亮。切换或关闭照片组时更新。

验收使用隔离图库中的真实横竖幅照片。分别在宽窗和窄窗检查首屏球体与照片的比例、总览与放大时的海陆与湖泊、转动时点位与展签的可达性、选择后点位与展签的反馈及底图一致性，以及大图返回路径。公开发布所需的地图审核按最终底图和呈现方式另行核对。

首轮取样为 17 张公开许可的实拍作品，覆盖北京、天津和天山天池。测试采用来源页面记录的相机位置写入隔离图库，用于核对北京 12 张、天津 2 张和新疆 3 张的地区归属。
