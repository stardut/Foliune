# 拍摄策划：场景与镜头清单

## 本轮场景与问题依据

用户要求保留每个场景的镜头清单，整理凌乱排版，并让每场景以 1–3 张参考组织拍摄。现有 `final-shot-wide.png` 中镜头参考铺成大图、拍法分列、各层间距较大；镜头列表难以连续扫读。本轮沿用中性深色连续背景、既有系统字体和控件，只调整策划内容编排。

## 方案

阅读与编辑统一采用「场景标题与拍摄要点 → 场景参考 → 镜头清单」。场景使用清晰序号和统一对齐；共同安排使用紧凑信息网格。场景参考一张时为适度主图，二或三张时采用等宽同高影像带，全部 contain 保留完整构图，逐图意图紧邻其图；不再将一幅大图和零散窄图混排。旧超限参考全部呈现并明确提醒，编辑可移除至最多三张，绝不截断。

「镜头清单」标题始终可见。结构化镜头采用紧凑有序行：名称、优先级、关键拍法与构图常驻，姿态、光线、情绪和历史镜头参考进入可发现的详情。编辑保持相同层级，名称与优先级在行首，关键拍法与构图小表单并排，细项按需展开；保留已有字段与参考，绝不把历史镜头图片猜测归入场景。自由文本清单与结构化镜头共用同一区域：已有文本直接显示，空文本通过「补充清单」打开，避免同时铺空白大表单，不要求二者同时填写。

全案概览压紧间距；总体参考保留为按需展开的轻量区域，全部数据仍可读取、编辑、导出。场景和镜头增删、排序、删除确认、稳定 ID、dirty/busy、失败保留及键盘路径延续。0 张参考可保存草稿；新选场景图最多三张，总参考 120、场景 20、镜头 100 的上限不变。保存错误指出具体超限场景。

## 导出与验收依据

PNG 同步场景顺序与清单语义：标题和要点、场景参考及各自意图、清单文本和结构化镜头详细字段；历史镜头参考保留在对应镜头下。2–3 张场景图在同一行完整居中显示，意图留在对应列。仍逐张解码、不截 DOM，任何缺图拒绝整个导出，1080 宽、32768 边长、40MP、64MiB 限制不变。

自动验证覆盖内容完整性、场景/镜头/参考顺序、独立意图、自由文本清单、历史超限引用保留与具体报错，以及真实 renderer 的同行布局、释放和失败。主代理在独立测试图库做 release 原生宽窗与最小约 920 逻辑宽检查，覆盖 1/2/3 张混合比例、首中尾、展开/收起、编辑与键盘操作；构建与 Node 检查不替代设计通过。高级与质感通过完整摄影参考、连续背景、稳定对齐和清楚执行顺序落实，最终观感以独立原生验收为准。
