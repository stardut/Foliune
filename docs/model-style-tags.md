## 范围与方案

用户要求常用风格标签可直接点击选择，用户可增减，不使用下拉。沿用当前模特编辑器、深色控件与已保存tags数组；不增加跨档案的标签字典管理或数据库迁移。

预设采用自然、清新、复古、胶片、日系、法式、时尚、街头、电影感、情绪、黑白、极简、古风、运动。默认不自动选中；平铺多选胶囊，点击选择、再次点击移除，以选中表面和勾号表达状态，保留键盘与禁用反馈。已有非预设标签继续展示，并可移除；新标签用输入和添加按钮或Enter加入，输入本身不提交整个档案。

只改变当前档案的标签集合。自定义输入参与未保存状态，直接保存时合并未确认文本，保存失败保留输入；沿用trim/去重及最多50个、每个80字符限制，不静默截断或丢弃。照片、档案其它字段和首页布局不变。
