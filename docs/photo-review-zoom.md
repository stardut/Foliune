# 大图缩放与拖动（2026-11-02）

## 场景与方案

用户要求大图支持滚轮缩放、拖动查看细节、双击放大或恢复适合窗口，其他样式保持不变。沿用既有查看模式、深色舞台、控件、完整构图与图片切换动效，不增加常驻工具或教学文字。

- 默认适合窗口，倍率1；滚轮以指针所在位置为锚连续缩放，限制1–8倍。只在照片区域处理，标准化滚轮deltaMode并阻止该区域网页滚动/浏览器缩放。
- 双击实际照片像素：适合窗口时放大至2倍并以点击位置为锚；已放大时恢复适合窗口、居中。边缘空白、顶部窗口区域和工具不触发照片缩放。
- 放大后按住左键拖动，使用指针捕获；依据完整照片在舞台内的contain尺寸约束偏移，较小的轴保持居中。结束、取消和失去捕获时清理拖动状态。
- 新照片、原图地址变化、错误及退出重置；同照片缩略图升级原图保留。窗口尺寸变化重新约束偏移。缩放变换与既有过渡变换分层，不覆盖切换动画或依赖其完成。
- 保持顶部窗口拖动/双击、Esc返回、左右切换、工具栏隐藏与Tab唤醒。默认全图可见，照片不被业务裁切，原文件不变。

## 验收依据

独立图库真实横竖摄影，检查滚轮锚点、放大拖动与边界、双击恢复、不同照片重置及窗口手势不冲突；检查240ms切换和idle仍可用。几何及真实事件回归补充deltaMode、非passive事件、resize、取消/失捕获、卸载及异步照片交接。原生操作与自动回归分别记录，不把构建或静态截图当完整手势验收。

## 实施

正式3文件：新增局部 `ReviewZoom` 输入/几何控制器；PhotoReviewImage增加独立内层与实际图片加载后的尺寸刷新；CSS仅增加内层、放大时裁切与触摸拖动约束。既有外层240ms切换动画、PhotoReview顶部拖区及键盘逻辑未改。

原生wheel用非passive监听，仅命中当前缩放/平移后可见照片矩形才消费。按像素/行/页标准化delta，限制每事件幅度并指数缩放1–8。几何优先实际DOM图像naturalWidth/Height，未加载时元数据承托，加载后重新夹紧。拖动拥有指针capture并在up/cancel/lost、新身份、resize及卸载清理；已拖动后短期抑制误双击。同ID/URL的缩略图升级原图保留姿态，新ID/URL及错误重置，退场层保留旧姿态且不响应手势。

最终类型检查及macOS release `.app` 构建通过，资源 `index-B0R1rfyT.css` / `index-BLs69EP2.js`；已确认打包JS含imageLoaded刷新。只有既有api.ts动静态导入分包提示，未新增IPC或持久化变更。

## 体验精修方案（2026-11-02）

用户后续实看确认“功能都有”，但反馈滚轮缩放速率低、不跟手，双击直接跳变太生硬。本轮以此反馈为起点，不将前一轮受锁屏限制的原生记录当成体验已通过。

当前代码滚轮指数增益为0.002，标准化100像素对应约1.22倍，较小滚动变化更弱；每次输入还反复读取命中、夹紧与全层绘制几何。前者是明确参数事实，后者是优化点，不据此断言已经测得帧延迟根因。

目标：提高约3倍滚轮灵敏度，输入持续直接响应，不用追赶、惯性或全局CSS transition拖慢滚轮/拖动。仅双击使用约220–260ms柔和比例及位移插值；动画中滚轮、拖动或再次双击须从当前显示姿态接管，不跳到旧终点。减少动态效果时立即交接；切换身份、错误、窗口变化和卸载均清理。其他样式、1–8范围、fit/2倍语义、像素命中/边界及外层照片切换动效保持。

双击独立240ms rAF cubic ease-out，对比例与偏移插值，每帧pose对应显示值；滚轮、拖动取消后就地接管。快速双击按未完成的目标反向，mousedown暂存被打断目标意图，避免恢复途中再次双击仍继续恢复。同身份thumb→original动画延续，逐帧查当前注册图层；实际移除旧节点后旧geometry读取抛错的回归仍能完成。reduced即时交接，resize、身份/URL/错误及detach清理动画和捕获，陈旧tick不能覆写新输入。

## 滚轮连续性精修（2026-11-02）

用户再次反馈滚轮仍生硬，明确双击动画与其他样式保持。本轮仅调整wheel插值，不继续提高增益。目标倍率按现有0.006累计，输入合并为唯一可重定向rAF；首事件同步产生可见变化，随后以约40ms时间常数的有限时log倍率插值，在最后输入后100ms内收敛。反向输入以当前显示倍率重新起算并立即反向，不先追旧目标；不增加惯性、事件队列或全局CSS transition。

最新指针位置作为锚，显示pose为手势接管真值。拖动或双击接管时取消wheel，原有240ms双击算法及反向语义保持；新显示身份、错误、resize、关闭/reduced清理，同身份原图交接延续。样式与既有双击算法已记录基准，最终核对范围。
