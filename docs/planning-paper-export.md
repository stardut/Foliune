# 策划长图：连续白纸与场景章节

2026-11-03 用户确认：本轮只调整供手机阅读的 PNG 长图；应用内场景卡片保持。此前产品约定及长图卡片文档中关于 PNG 灰底、圆角卡片和描边的描述作为历史记录，以本方案为准。

## 场景与视觉方案

长图用于拍摄前分享、手机查看及现场核对。使用一张连续白纸，以排版与章节节奏组织信息，照片保持完整构图和主要视觉权重；不把应用深色外壳及场景卡片复制进纸张。

- 画布保持 1080px 宽，白底；左右单层 64px 页边距，正文可用宽度 952px，取消灰底、卡片背板、圆角、卡片描边和二次内缩。
- 开篇概览与整体视觉直接排在纸面，整组准备仅出现一次且位于首场景之前；相邻分组以 36px 留白衔接，不增加分割线。
- 每场景前留 56px 间距，绘制一条 2px 浅灰线，再留 32px 进入标题。场景内部依靠既有小标题与间距分区，不逐区加线。场景间节奏大于内部间距。
- 场景编号与名称保留 48px，时段保留 36px；短内容相邻同排，长标题或长时段完整换行。保留参考图、拍摄参数、镜头清单三区、40px 正文、36px 标签与图注及所有历史文字。
- 参考图最多两列，单图居中；第三张及历史更多图片保留半列续行。逐图意图跟随其对应列，不裁切、不拉伸。
- 执行准备在文末以 48px 留白和短标题自然收尾，不增加背板或分割线。

## 实现边界

仅修改导出内容模型、Canvas 测量与渲染及其测试。将显式卡片边界改为语义章节边界，以 scope 区分概览、整组准备、场景和执行准备；只有场景 scope 产生细线，不依赖用户文本判断章节。移除卡片几何，所有内容复用单层页边距。

不修改应用 UI/CSS、场景编辑、PlanParts、IPC、Rust 或持久化。保持原图逐张解码与释放、缺图拒绝、32768px 单边／4000万像素／64MiB 限制及 Canvas 清理。

## 验收依据

自动检查连续白底、无卡片绘图、统一边距、场景线条数量及不穿过内容、章节归属与边界、全文保留、长标题与时段无重叠、0–4 张混合比例参考图、缺图及资源释放。原生导出与手机 375/390px 阅读样张由独立验收记录补充；单元测试不视为视觉质量通过。
