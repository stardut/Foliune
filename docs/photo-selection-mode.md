# 照片墙的浏览与选择模式

2026-10-31，用户要求照片默认浏览、照片无悬浮选择框和三点入口，经右键选择后进入多选，退出后不再点击选择。

## 实施边界

照片优先，沿用背景、照片布局、构图和现有控件语言，仅改变照片墙选择门槛与操作入口。按2026-11-01用户最新要求，浏览态单击打开已有大图预览，不改变选择，照片详情继续通过右键菜单访问；照片墙不再设置双击详情处理，避免一次点击打开预览后再串开详情。右键/Shift+F10/ContextMenu打开菜单本身不修改选择。通过菜单选择首张后，各图可点击增减选择。已选数为零即退出模式，取消选择/Escape/换相簿同样退出。右键对象和批量范围保持既有规则，不修改原图或相簿关系。共享PhotoImage在选片器等场景行为不变，缺失照片仍保留重新定位与菜单访问。

验收覆盖展览/总览：普通点击不选、右键取消不选、菜单选一张、点其他图增减、清选及Escape后再点打开预览且不选、切相簿重置、键盘菜单。必要反馈在模式内可见且可访问，默认照片不标成选择toggle。操作栏可保留批量更多；不保留照片三点入口。

## 单击预览修订（2026-11-01）

场景与方案：普通浏览时点击作品直接进入已有PhotoReview大图，沿用其照片顺序与关闭行为；处于选择模式时点击只增减选择，不能同时打开预览。右键及键盘菜单继续选择和操作，打开菜单不改变状态。清选/退出后下一次点击恢复预览。仅接通现有previewId入口，不改预览版式、照片布局、样式或持久化。

验收包括浏览点击→目标大图→关闭、右键取消不预览、右键选首张→点另一张只增选、退出后点击恢复预览，以及回归脚本/类型构建/独立审查。
