# 按钮、字体与相簿卡片统一

2026-10-30，用户暂停材质探索，要求优先优化按钮/字体与主题的协调性，并把相簿改为上图下字的一体卡片，图片填满上方主要区域，名称有设计感。本轮保持现有背景/native配置不变，不接入原生实验。

## 场景与方案

收藏/作品相簿浏览为代表页，照片优先。现状问题：按钮与选中导航强银色分段渐变像独立金属贴片；卡片图文分离、封面有大面积留边，标题与控件同样细小缺少层级。

控件采用同一中性深色的细腻实体表面、柔和浅色选中态，去强金属高光断层和重阴影，点击范围/焦点/禁用保持清晰。UI正文沿用系统无衬线，不全局放大；名称层用克制的衬线展示字体，形成摄影出版物的识别感，不添加英文编号、装饰标签或冗余文案。

相簿作为一个可键盘打开的完整卡片，统一圆角轮廓，上方约75%为3:2封面，图片满铺无内缩，底部约72px以足够内距承载名称与数量；宽三列、窄两列，长名可两行。空相簿保留安静的占位图标与相同结构。仅相簿封面预览按用户明确要求用object-fit:cover；照片墙、单张审片与画册原有构图规则不变。

## 实施/验收边界

优先使用现有theme/index/library及AlbumOverview结构，必要时少量调整DOM；不改业务数据与图库操作。字体/基础控件调整须检查画册纸张及独立导出隔离，不把全局展示字体灌入纸张。状态覆盖默认/悬停/按下/禁用/焦点、导航选中、长名、空相簿、混合比例封面与宽窄卡片。

前端类型/构建与macOS原生包，独立源审及真实测试图库原生检查。保留首页宽窄/弹窗/相簿打开/已有画册证据。背景及材质不作为本轮通过目标，不重新消耗材质试验。

## 实现与检查过程

实现为4CSS：theme的控件/导航/封面tokens由强金属渐变改中性实体面；index按钮/导航13px系统sans、500字重、细微字距，去重高光；library整卡12px圆角，上3:2满铺封面、下76px文字区，名称18px Georgia/Songti；books仅给纸张缺图按钮补400字重/normal字距隔离。AlbumOverview结构、事件、ARIA、数量与未归入入口无改动。surface/native配置保持，不接实验。

首原生包发现方图/竖图仍留黑：library中.album-cover img与后加载index的.image-asset >img同优先级，被contain覆盖。已修至.album-cover .image-asset >img，原生final-wide及narrow-bottom确认真实满铺。独立源审另指出纯色导航底若仍background渐变会短暂深字深底；已去导航背景过渡，仅保留box-shadow，避免状态不同步。

最终前端类型/生产构建通过，资源`index-TuZJGD0s.css` / `index-D-v5Hpm4.js`，macOS release最终构建通过，Avenil验收实例最终PID52640。源码前后/冻结和所有原生图在`.build/verification/controls-albums/`。

主代理已实际检查宽窗三列/窄窗两列、窄窗滚到第二排尾部、空相簿、真实宽/方/竖封面；新建弹窗打开取消，Tab聚焦卡片后Space打开相簿，选择首图/清选（工具栏立即卸载），打开既有3页手工画册未编辑。照片墙与白纸/字幕保持原构图/字体。长中文名称两行、缺图及hover/active细节目前主要为源检；未为截图直接写DB或改样本名字，不将其算完整原生验收。

最终原生包已加载，实际切换作品→画册→收藏，选中深字/浅底与未选浅字/深底对应，回到宽窗收藏首页。最终首页`final-wide.png`已更新，另存`final-nav-work.png`与`final-nav-books.png`；其余代表图来自仅差导航过渡一行的上个包，相关卡片/纸张/表单规则与最终包相同。没有把静态图当完整动效/性能通过。
