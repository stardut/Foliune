# Foliune 欣赏配乐

两首音乐为本项目原创程序作曲与声音合成，没有使用第三方录音、音乐、采样包或预设音色。谱面、旋律、和声、鼓组及混音在 `scripts/compose-player-music.py` 中完整可复现。脚本仅在重新生成资产时依赖 Python 3 与 NumPy；应用播放不依赖它们。

本目录两首 WAV 及对应作曲脚本以 **CC0 1.0 Universal** 提供，允许免费使用、修改、复制及随项目分发（包括商业用途），无需署名。许可文本：[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/legalcode)。这项资产许可不改变 Foliune 其它代码及素材的许可状态。

音频为 22,050 Hz、16-bit、双声道 PCM WAV，合计约 3.74 MiB。无压缩格式的编码前导延迟，循环长度取实际 PCM 帧数；混响与延迟尾音按循环回卷渲染，避免循环处突然切断。第一个鼓点及和弦从时间零开始，随后每小节第一拍是可用于切图的重拍。音轨的听感仍需在桌面播放设备上验收。

`src/lib/player-music.ts` 提供每拍和每小节重拍的精确时间。`usePlayerClock` 以 `HTMLAudioElement.currentTime` 为唯一音乐时钟，选择接近停留值的小节重拍；不会让累计定时器误差改变节拍相位。暂停后恢复重新确定停留目标；同一照片短暂重组或等待原图时保留目标，错过的重拍不补切，在照片就绪后的下一重拍继续。静音及本地分析无法确定重拍时使用固定停留值。

本地音乐分析完全离线：先检查媒体元数据，最多 10 分钟与 24 MiB；随后以 OfflineAudioContext 在 11,025 Hz 解码并平均声道，低通能量包络检测实际瞬态、自相关估计稳态脉冲，再以每四拍能量辨认强拍。输出是推断的小节重拍，不是人工标注乐谱；无稳定节拍、缺乏强弱拍证据、变速、格式不支持或资源超限时返回明确的 `fixed` 原因。Web Audio 原生解码不可被 AbortSignal 中止，取消会终止下载并丢弃迟到的解码结果。不会上传音频或改变导入文件。
