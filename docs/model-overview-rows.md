# 模特首页横向档案行（2026-11-03）

最新固定行修订：用户明确所有档案（含无样片）保持相同行高，悬停反馈更清楚、文字远离边缘。本轮采用144px固定行，照片仍最多120px，行上下12px、左右20px内距；沿用现有control-hover悬停表面提高可辨识度，保留键盘定位。姓名最多两行、基本信息／风格单行适度省略，完整内容仍可在详情查看，不让文字反撑行高。此修订取代下文空档案自然收紧的历史规则。

上一轮密度修订：用户继续要求行高降低、首页不显示样片数量。样片默认／上限改为120px，列表间距16px、行上下内距8px；左侧只保留姓名、性别／城市和风格，缩小对应内距与标签间距，避免信息反撑行高。沿用一行一位、完整等高照片及原有选图规则，详情页不受本轮影响。下文200px与数量属于上一轮历史方案，密度修订的实际验收补在文末。

## 用户场景与本轮修订

用户明确否定上一版三列卡片的视觉：横竖照片在大小不等的格子内留下零碎空白，空档案占据巨大图块。此前功能验收不代表该设计已被用户认可。本轮只调整首页，采用一行一位模特，左侧基础信息、右侧样片，保留点击详情和显式编辑流程。

信息列集中姓名、性别／城市、少量风格和样片数；样片区使用直接等高、等比例照片，去掉大卡片底板和套格黑边，以对齐、间距和照片本身建立秩序。空档案使用短空态并收紧行高，不占一整块封面空间。沿用中性深色变量和现有字体，整行保留点击、悬停和键盘定位，不增加方向说明标签。

## 选图与几何规则

首页最多3张样片，从完整档案中选择：竖构图或横构图（含方图）有一组足3张时优先同组；两组都足3张时以有效封面所在组优先，否则按业务顺序选择。没有组足3张则取原序前3，展示时竖图在左、横图在右分组，组内业务顺序不变。此为首页选择和分组，不修改已存样片顺序、封面或详情。

所有选中图片以共同显示高度、各自原比例展开；根据右侧真实可用宽度和总比例计算共同高度，上限200px，窄窗整体缩小以完整容纳。横、竖图在混合行保持相同高度，不裁切、拉伸、堆叠或显示半张。窄窗仍保留左信息右样片。照片默认可见，业务可见性不依赖动画。

## 验收依据

功能检查同横／同竖优先、混合分组和组内顺序、缺图、空样片、单张、极宽比例及宽度适配；不改变原有样片引用和顺序。使用独立图库真实摄影副本检查宽窄窗口首段／中段／末尾，确认行层级、图片等高完整、信息可读、空态紧凑及点击／键盘进入详情。类型、构建、定向几何检查与原生图审分别记录，不以构建成功代替设计验收。

## 实现与验证

新增局部`ModelOverviewRow`，首页改为纵向档案行；选图和纯几何计算复用现有state模块，样式仅限models.css。图片初始200px默认可见，useLayoutEffect同步测右列宽度，ResizeObserver处理窗口变化；按比例计算每张宽度和共同高度，不依赖动画完成或首次异步回调才显示。空行随信息内容自然收紧。详情、编辑、IPC和存储未修改。

开发及独立审查各运行11项模特检查通过，包含真实首页／详情组件、同方向选择、混合顺序、方图、缺失重复、0／窄宽度和10:1横图等几何约束；独立补充选图与几何组合验证通过。共享策划模块并行调整曾使整包类型检查失败，待其修正后最终typecheck、前端及两种macOS release构建通过；未修改策划模块，也不将该模块本身纳入本轮验收。
