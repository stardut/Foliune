# 深色磨砂工作区重设计方案

## 场景与目标

2026-10-30，用户要求参考其截图重新设计整个页面的样式和布局：顶部集中导航，下方内容，统一高级深色调与磨砂/毛玻璃质感。执行 [设计规范](design.md)，延续现有图库、画册、欣赏、搜索与设置能力。

现状：原生选片验收实例仍采用浅色背景、左侧排列的顶部导航和大面积浅灰封面托底；源码包含共享样式以及图库、画册、播放器各自样式。需要整体更新外壳与控件，覆盖功能面板，避免仅更换背景。

## 视觉与布局方案

- 顶部为稳定导航区：左侧精简品牌，中间集中胶囊导航（收藏、作品、画册），右侧搜索、设置；选中项用柔和浅色表面建立焦点。窄窗保持三个区域不重叠。
- 内容位于导航下方：页头组织标题、数量与本页主操作，随后为相簿/画册陈列、照片墙或工作面板。不套用参考图的系统监控卡片内容。
- 底色为近黑烟褐，局部暖橄榄灰柔光；导航、面板和浮层采用有层级的半透明表面、细描边、边缘高光和柔和阴影。摄影承托底采用中性深灰。
- 用统一变量维护色彩、材质、圆角和控件状态；适度收紧封面托底与留白，让作品和标题关系更完整。照片原比例、业务顺序与展览算法保持现有规则。
- 图库、选片、详情、画册工作区、搜索和设置使用相同控件语言；画册纸张与独立 HTML 导出保持自身排版和颜色。播放器内容优先，工具沿用新的质感。
- 本轮先实现窗口内的磨砂层次：真实 CSS 半透明和背景模糊配合底层柔光。不得把窗口内效果称为已经透出桌面壁纸的系统材质；如调整宿主窗口，仅限本方案所需，先核实平台能力与构建限制。

## 状态与交互

保留原有操作、脏数据离开确认、右键菜单、键盘与焦点路径。更新默认、悬停、按下、选中、禁用、焦点、加载、空态和错误视觉。关键内容默认可见，关闭直接卸载；动效支持减少动态效果。

## 验收

1. 类型检查与前端生产构建；有宿主改动时增加对应检查。
2. 独立实例/图库，真实摄影宽窗 1320×880、窄窗约 920×620，检查相簿、照片墙首中末、详情/放大挑选、画册/纸张、搜索、设置、弹窗与菜单。
3. 实际检查导航、选择与清选、关闭与焦点、滚动与动效、文字对比，保存前后截图与交互证据；功能和设计分别记录，独立验收。
4. 未测平台、外部 AI 与分发能力不推定通过。当前方案不改数据库或原件，不在运行中 SQLite 写入测试结果。

## 交付状态

已完成整体样式与顶部布局实施，并完成本轮范围内的原生操作、独立代码审查及截图验收。详细证据保存在本地桌面验收记录。

### 实施结果

- 顶部改为品牌、居中胶囊导航、工具三栏；统一深色变量集中在 `apps/desktop/src/theme.css`，原有样式声明直接更新。
- 相簿陈列、图库控件、详情、选片、搜索、设置、画册编辑与阅读外壳、播放器、菜单和弹窗统一材质；照片采用中性承托，画册封面保留纸张气质，纸张内部变量与排版隔离。
- 宿主设置 `theme: Dark` 与深色初始背景，保留系统标题栏、窗口装饰和拖动语义。未开启透明窗口、Overlay 或私有 API；磨砂效果为窗口内部的分层表面与局部背景模糊。
- 独立验收发现并返修了滚动时亮照片削弱顶部导航对比、窄窗创建画册底部操作不可见两项问题。顶部使用稳定的深色承托；创建弹窗固定标题、步骤和提交区，正文独立滚动；选片标题与图片边界同时修正。
- 类型检查、前端生产构建、macOS release `.app` 构建通过。独立验收确认返修问题关闭，本轮已观察范围的功能与设计分别通过。
- 当前仅代表本次样本与操作覆盖；减少动态效果、创建弹窗鼠标滚轮、Windows、独立导出实测、真实外部 AI 与正式分发未验证。未作性能基准或与参考产品等价品质的认证。
