# 大图顶部单行工具栏（2026-11-02）

## 用户场景与方案

用户指出返回/名称占顶部、左右切换占底部，浪费纵向空间；进一步明确要与macOS红黄绿控制点位于窗口顶部同一行。

采用顶部固定约32px单行：左侧为系统traffic lights留约84px安全区，其后短“返回”（完整可访问名称仍为返回照片墙）；中间名称单行省略、全窗视觉居中；右侧既有上一张/页码/下一张胶囊。移除底部工具栏和原safe-top叠加行，照片舞台直接利用余高，保留必要边距与完整构图。沿用现有深色和控件语言，不新增提示/装饰。

已有验收窗口采用Overlay及hiddenTitle，沿用该窗口能力，本轮不更改原生配置。持久header-region承载deep窗口拖动/双击，内部toolbar随idle隐藏且inert；按钮和整组navigation明确阻断drag，包括SVG和页码。无绝对拖动蒙层罩住按钮，系统红黄绿不被自定义操作占用。隐藏不移除行，不使照片跳尺寸。

范围仅PhotoReview与专用CSS及对应回归；照片准备、已认可滚轮、拖动、双击和切换动效不变。宽/窄窗、长名称、首末禁用、键盘Tab/箭头/Esc、隐藏及窗口手势分别检查，构建与原生视觉证据分开记录。
